# ⚾ KBO 2026 애슐리 퀸즈 - 야구 응원가 & 전광판 매니저 사용 매뉴얼

[![Developer: 정승찬](https://img.shields.io/badge/개발자-정승찬%20(jscsarik)-blue.svg)](https://github.com/jscsarik)
[![Standalone Executable](https://img.shields.io/badge/실행-Python%20없이%20즉시실행-success.svg)](#)

> **"야구 게임(Super Mega Baseball 4 / KBO)을 플레이하며 타순별 등장곡·응원가를 켜고 전광판을 보는 올인원 중계 매니저"**  
> 단축키 하나로 1번부터 9번 타자의 전용 등장곡 40곡과 22인 선수단 고화질 얼굴 프로필 카드를 실시간 송출합니다.

---

## ⚡ 1. 3초 퀵 스타트 (실행 방법)

**Python 설치가 전혀 필요 없습니다!**

1. 이 폴더 안에 있는 **[`dist/kbo_cheer.exe`](./dist/kbo_cheer.exe)** (또는 [`실행하기.bat`](./실행하기.bat)) 파일을 마우스로 **더블클릭**합니다.
2. 즉시 세련된 다크 테마의 애슐리 퀸즈 야구단 전광판과 응원가 제어 센터가 열립니다!
3. 이제 게임을 켜고 키보드의 `F1`~`F9`를 누르면 신나는 응원가가 터져 나옵니다.

---

## 🎹 2. 키보드 단축키 조작표 (치트 시트)

게임을 전체화면으로 플레이하고 있어도 백그라운드에서 키보드 신호를 완벽하게 잡아냅니다:

| 단축키 | 기능 및 동작 설명 |
| :---: | :--- |
| **`F1` ~ `F9`** | 1번 타자부터 9번 타자까지 순서대로 해당 선수의 **등장곡** 즉시 재생 |
| **`Ctrl + F1` ~ `F9`** | 해당 선수의 **팀 공식 응원가** 재생 (무한 루프 신나는 합창) |
| **`F10`** | 현재 마운드에 등판해 있는 **투수의 등장곡** 재생 |
| **`F12` 또는 `Space`** | 재생 중인 모든 음악 즉시 **정지 / 음소거** |
| **타순 클릭 / 드래그** | 화면에서 1번~9번 타자의 이름 및 수비 위치(LF, CF, 1B 등) 실시간 변경 |
| **투수 교체 탭 클릭** | 선발 로테이션(권영호 ➔ 이지원 ➔ 김규태 ➔ 김병서) 및 불펜진 즉시 교체 |

## 🏟️ 3. 전광판 & 시각화 기능

* 🖼️ **22인 선수단 얼굴 프로필:** 등번호(서석진, 김상훈, 김민석, 이유준, 이정학, 김진욱, 백찬하, 김범진, 정승찬 등)와 1:1 매칭된 고화질 프로필 카드가 전광판에 자동 합성됩니다.
* 💎 **다이아몬드 수비 포지션 뷰:** 현재 타석에 선 타자와 마운드의 투수가 야구장 다이아몬드 그래픽 위에 하이라이트 표시됩니다.
* 💾 **라인업 자동 저장:** 내가 수정한 타순과 포지션 배치는 프로그램 종료 후에도 안전하게 자동 보관됩니다.

## ❓ 4. 자주 묻는 질문 (FAQ)

### Q1. 게임 중에 단축키를 눌렀는데 소리가 안 나요!
> 👉 게임이 관리자 권한으로 켜져 있으면 윈도우가 일반 프로그램의 키 입력을 차단합니다. `dist/kbo_cheer.exe` 또는 `실행하기.bat`를 **마우스 우클릭 ➔ [관리자 권한으로 실행]**해 주시면 게임 플레이 중에도 단축키가 100% 먹힙니다.
