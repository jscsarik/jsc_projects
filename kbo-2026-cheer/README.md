# ⚾ KBO 2026 Cheer & Profile Manager (애슐리 퀸즈 야구단 응원가 및 전광판 송출 매니저)

> **Super Mega Baseball 4 / KBO 가상 야구 리그 '애슐리 퀸즈 (ASHLEY QUEENS)' 전용 실시간 응원가 및 선수단 프로필 송출 매니저**  
> 게임 프로세스 자동 감지(Auto Launcher), 타순별 등장곡/응원가 글로벌 단축키 재생, 22명 선수단 고화질 얼굴 프로필 카드, 3:4 스포트라이트 전광판 및 수비 다이아몬드 실시간 시각화를 지원하는 올인원 브로드캐스트 시스템입니다.

---

## 📌 주요 특징 (Key Features)

- 🎵 **실시간 등장곡 & 응원가 원클릭 제어 (CustomTkinter + Pygame)**
  - 1번~9번 타순 및 투수진 전용 등장곡 / 응원가 MP3 음원 총 40곡 탑재.
  - `keyboard` 훅 기반의 **글로벌 단축키(Global Hotkeys)** 지원으로, 게임 플레이 중 전체 화면 상태에서도 백그라운드에서 즉시 음원 재생, 교차 정지, 볼륨 페이더 조절이 가능합니다.
- 🖼️ **선수단 얼굴 프로필 & 중앙 전광판 스포트라이트 (Profile Spotlight)**
  - 선수별 등번호(0: 서석진, 3: 김상훈, 8: 김민석, 9: 이유준, 10: 이정학, 15: 김진욱, 25: 백찬하, 30: 김범진, 66: 정승찬 등)와 1:1 매핑된 고해상도 얼굴 프로필 자동 연동.
  - 전광판 3:4 비율 세로 카드에 팀 공식 엠블럼, 골드 테두리 정보 바, 등번호 및 1st/2nd 포지션 태그를 실시간 합성하여 렌더링합니다.
- 🏟️ **야구장 다이아몬드 수비 실시간 시각화 (Diamond Field Visualizer)**
  - `Pillow` 그래픽 엔진을 활용하여 현재 수비 포지션(LF, CF, RF, 1B, 2B, 3B, SS, C, DH)과 현재 타석 타자 및 마운드 투수를 다이아몬드 그래픽 위에 하이라이트 표시합니다.
- 🔄 **선발 투수 4인 로테이션 & 불펜진 실시간 교체**
  - 선발 로테이션(권영호 ➔ 이지원 ➔ 김규태 ➔ 김병서) 순환 관리.
  - 승리조/필승조/마무리 불펜진(이권희, 김준겸, 오동환, 이정용, 이제임스) 원클릭 마운드 교체 및 등장곡 즉시 송출.
- 🤖 **게임 자동 감지 및 백그라운드 런처 (Auto Launcher)**
  - `psutil` 및 `win32gui`를 활용하여 `supermegabaseball.exe` 실행 여부를 1.5초 주기로 감지.
  - 게임 실행 시 응원가 매니저 자동 기동, 게임 종료 시 자동 백그라운드 정리를 지원하는 `auto_launcher.pyw` 데몬과 원클릭 실행 배치파일(`SMB4_게임실행.bat`)을 제공합니다.
- 📋 **라인업 저장 및 복구 (`lineup.json`)**
  - 드래그 앤 드롭 수준의 직관적인 GUI에서 수정한 타순, 포지션, 활성 투수 설정을 JSON 포맷으로 자동 영구 보관합니다.

## 🛠️ 기술 스택 (Tech Stack)

- **Language**: Python 3.10+
- **GUI Framework**: CustomTkinter (`customtkinter`), Tkinter
- **Audio Engine**: Pygame (`pygame.mixer`)
- **Graphics & Visualizer**: Pillow (`PIL.Image`, `ImageDraw`, `ImageOps`, `ImageFont`)
- **System Integration & Hotkeys**: `keyboard`, `psutil`, `pywin32`
- **Target Platform**: Windows 10 / 11, Super Mega Baseball 4 (Steam App ID: `1487210`)

## 💡 글로벌 단축키 & 조작 가이드

| 단축키 / 기능 | 동작 설명 |
| :--- | :--- |
| **`F1` ~ `F9`** | 1번 타자부터 9번 타자까지 순서대로 해당 선수의 **등장곡** 재생 |
| **`Ctrl + F1` ~ `F9`** | 해당 타자의 **응원가** 재생 (무한 루프 / 합창 모드) |
| **`F10`** | 현재 마운드에 올라와 있는 **투수의 등장곡** 재생 |
| **`F12` / `Space`** | 현재 재생 중인 모든 음원 즉시 **일시 정지 / 음소거** |
| **타순 클릭 / 드래그** | GUI 상에서 1번~9번 타자 이름 및 포지션(LF, CF, 1B, DH 등) 변경 |
| **투수 교체 탭** | 선발 투수 로테이션 클릭 또는 불펜 명단 클릭 시 즉시 마운드 교체 |

## 🚀 빠른 시작 (Getting Started)

### 1. 사전 요구사항
- Python 3.10 이상
- Super Mega Baseball 4 (또는 KBO 야구 게임)

### 2. 필수 패키지 설치
```bash
pip install -r requirements.txt
```

### 3. 프로그램 실행
```bash
# GUI 응원가 & 전광판 매니저 직접 실행
python main.py

# 또는 게임과 함께 백그라운드 자동 연동 실행
SMB4_게임실행.bat
```
