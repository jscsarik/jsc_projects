# 25차 자동 시뮬레이션

실제 사용자 저장 파일을 사용하지 않는 진단 전용 실행기입니다. 기존 서비스·판정 엔진을 그대로 호출하며 게임 규칙과 UI는 변경하지 않습니다.

프로젝트 루트 PowerShell:

```powershell
.\.venv\Scripts\python.exe tools/simulate_game.py --output diagnostics/new_run --seed 250029 --seasons 1 --budget-seconds 360
.\.venv\Scripts\python.exe tools/analyze_simulation.py diagnostics/new_run
.\.venv\Scripts\python.exe -m unittest tests.test_simulation25 -v
```

새 실행은 비어 있는 별도 폴더를 사용합니다. 재개하려면 동일 경로에 `--resume`을 추가하고 목표 시즌을 지정합니다. 시간 예산은 10~900초이며 공식 처리 경계에서 중단합니다. 현재 기록은 `diagnostics/25_seed250029/분석_보고서.md`를 참고하세요.

1시즌 완주 후에만 확장하며 실패한 시즌 이후는 자동 진행하지 않습니다. 이번 실제 실행은 1시즌 완주, 2시즌 비시즌 진입 직전 신인상 후보 부재로 중단했습니다. 이 문제를 해결하기 전에는 같은 체크포인트에서 다시 중단됩니다.

10~20시즌 옵션은 향후 별도 요청 시 `--allow-long-run`과 함께 사용할 수 있도록 준비했으며 이번 작업에서는 실행하지 않았습니다. 동일 코드·설정·사진이 재현 조건이고 시드·난수 상태·입력 사진 해시는 별도 저장합니다. 실행 중 강제 종료에 대한 DB/RNG 동시 원자 복구는 보장하지 않습니다.

`simulation.sqlite3`, `checkpoint.json`, `simulation_summary.json`, `integrity_checks.json` 및 CSV를 함께 보존하세요. CSV의 빈 종료값은 시즌 미완료를 의미합니다. 테스트 플레이어 정책은 실제 9개 AI와 다르며 기본 게임 AI를 대체하지 않습니다. 세부 한계와 미검증 항목은 분석 보고서에 명시했습니다.
