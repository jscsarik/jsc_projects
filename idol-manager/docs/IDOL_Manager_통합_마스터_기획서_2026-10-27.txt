문서 목적: 확정·채택·미확정 게임 규칙을 하나로 관리하는 통합 마스터 기획서 (개발 참고 및 공유용)
기획 상태: 주요 규칙 설계 완료 / 날짜·로스터 회귀 오류 수정 및 경기 엔진·장기 시뮬레이션 개발 예정

======================================================================
0. 30초 요약
======================================================================

IDOL Manager는 풋볼 매니저(FM), OOTP, KBO 구단 운영 게임처럼
'아이돌 기획사' 하나를 맡아 10개 기획사 리그에서 우승을 노리는
Windows PC용 싱글플레이 경영 시뮬레이션이다.

- 플레이어가 10개 중 기획사 1개를 운영하고, 나머지 9개는 AI가 운영한다.
- 아이돌 이름과 얼굴 사진, 기획사 로고는 사용자가 지정한 폴더에서 읽어온다.
- 실제 인물의 실력이나 실제 나이는 반영하지 않고, 게임 속 나이·능력치·
  건강·숨겨진 잠재력은 가상으로 무작위 생성한다.
- 선수단은 1군 5명, 2군 최대 11명, 인원 제한 없는 연습생으로 구성한다.
- 정규 24주 + 포스트시즌 3주 + 비시즌 4주 = 31주. 각 기획사는 정규 경기 117회를 치른다.
- 경기는 콘텐츠별 능력치 성공/실패 판정으로 승부를 낸다.
- 드래프트, FA 계약, 연습생 육성, 트레이드, 부상, 노화, 재정 관리가 핵심이다.
- 매년 새로운 인물 70명이 등장하며 그중 특별 유망주 2명이 숨겨져 있다.
- 화면은 FM처럼 표와 메뉴 중심으로 만들며, 선수 사진은 작은 프로필로 표시한다.
- 개발 스택은 Python + PySide6 + SQLite이며 현재 진행 내용은 25장 참조.

문서 표기: [확정]=사용자가 직접 결정한 내용. [채택·구현 권장]=사용자가
추천안대로 업데이트하라고 승인한 방향(세부 가중치는 미정). [검증 필요]=
기존 규칙을 유지한 채 시뮬레이션 결과로 확인할 사항. [미확정]=아직 사용자
선택이 없어 임의로 확정하면 안 되는 세부사항. 후행 합의가 과거 제안보다 우선.
이 문서는 게임 '기획'의 최종 정리이며 코드 수정 완료를 의미하지 않는다.

1. 게임의 기본 방향 [확정]
======================================================================

장르           : 아이돌 기획사 경영 + 리그 경기 + 선수 육성 시뮬레이션
플랫폼         : Windows PC (로컬 실행형)
플레이 형태    : 싱글플레이 / 10개 기획사 중 1개 선택
상대           : 나머지 9개 기획사는 동일 규칙을 따르는 전략형 AI
진행 방식      : 하루씩 날짜 진행, 경기일에 출전자를 선택하여 경기 진행
화면 스타일    : 파스텔톤, 높은 가독성, 표·텍스트·버튼 중심
특별 화면      : 드래프트/라인업 픽창, 경기 대결실
우선 목표      : 실제 작동하는 작은 프로토타입부터 확장

기획사명 및 로고는 SM, JYP 등의 이미지 파일을 예시로 사용한다.
다만 게임 안의 성적·연봉·능력치·사건은 현실과 무관한 가상 데이터이다.
본 프로젝트는 개인용으로 기획되며, 외부 공개·배포 시 사진/로고의
저작권 및 상표 사용 권한을 별도 점검해야 한다.

2. 인물·이미지 데이터베이스 [확정]
======================================================================

- 사용자가 준비할 인물 프로필은 최초 800명 이상을 목표로 한다.
- 이름과 사진은 assets/idols/ 폴더에 넣으며 파일명으로 이름을 인식한다.
  예: assets/idols/아이돌A.jpg, 아이돌B.png, 아이돌C.webp
- 이름이 겹치는 경우 '이름__그룹명.jpg' 같은 방식으로 식별 가능하게 설계한다.
- 기획사 로고는 assets/agencies/ 폴더에 별도로 저장한다.
  예: SM.png, JYP.png, YG.png
- 인물마다 내부 고유 ID를 부여하여 이적과 세이브 후에도 기록이 유지된다.
- 사진을 추가하면 데이터베이스를 확장할 수 있다. 800명은 상한이 아니다.
- 새로운 게임을 시작할 때 게임 내 가상 나이, 현재 능력치, 건강, 잠재력을
  다시 생성한다. 이미 진행 중인 세이브의 기존 인물 정보는 유지한다.
- 한 세이브에 이미 등장한 동일 인물이 신규 인물로 다시 등장하지 않는다.
- 은퇴 선수도 경력 기록을 보존하며 활성 영입 시장에서는 제외한다.

최초 창단 과정:
- 200명이 최초 드래프트 후보에 등장한다.
- 최초 드래프트 후보 나이는 17~26세로 생성하는 현재 개발 규칙을 적용한다.
  구형 세이브의 16세 후보는 사용자 동의와 백업 없이 임의로 수정하지 않는다.
- 10개 기획사가 16라운드 드래프트를 치러 총 160명을 선발한다.
- 미지명 40명은 초기 FA 시장으로 이동한다.
- 최초 800명 기준 나머지 600명은 미래 등장 후보로 남는다.
- 첫 창단 드래프트와 이후 매년 3라운드 통합 드래프트는 별도 제도이다.

신규 인물 유입(첫 창단 이후 매년):
- 비시즌 1주차 시작 시 신규 인물 정확히 70명을 한꺼번에 공개한다.
- 나이 구성: 14~16세 60명, 17세 이상 10명으로 설계한다.
- 70명 모두 매년 통합 드래프트 후보가 된다.
- 신규 70명 중 '21세 이하'에서 정확히 2명을 무작위 추첨하여
  숨겨진 특별 유망주로 지정한다.
- 특별 유망주는 현재 능력치·특화 유형과 무관하게 선정되며, 실제 정체와
  숨겨진 잠재력 수치는 플레이어와 AI에게 공개하지 않는다.
- 인물이 부족해지면 사진을 추가해 계속 확장한다.
  참고: 초기 미등장 600명만으로는 70명씩 8개 시즌을 완전히 공급 가능하며
  이후 40명이 남는다. 다음 시즌부터는 추가 데이터가 필요하다.

3. 선수단과 신분 [확정]
======================================================================

[1군] 프로 아이돌 정확히 5명 편성
[2군] 프로 아이돌 최대 11명
[연습생] 등록 인원 제한 없음
[프로 총원] 1군+2군 최대 16명

- 연습생 영입 가능 나이: 만 14세 이상
- 프로 데뷔 가능 나이: 만 17세 이상
- 프로 데뷔는 기본적으로 비시즌 4주차에 최종 처리한다.
- 시즌 중 방출로 프로 자리가 생긴 경우에 한해 월요일에 FA를 영입하거나
  17세 이상 연습생을 프로 계약 후 2군으로 데뷔시켜 보충할 수 있다.
- 데뷔에는 실제 빈자리가 있어야 한다. 빈자리 없이 16명 초과 등록 불가.
- 연습생에서 프로(2군)로 올라간 뒤에는 다시 연습생으로 돌아갈 수 없다.
- 1군과 2군 사이 이동은 가능하며 월요일에 처리한다.
- 프로 데뷔 협상이 결렬된 연습생은 연습생 신분을 유지하고 나중에
  다시 데뷔 협상에 도전할 수 있다.

연습생 급여:
- 드래프트에서 지명되어 연습생이 된 선수: 데뷔 전까지 시즌당 1,000만 원.
- 드래프트 밖에서 자유계약으로 확보한 연습생: 연봉 0원(무급).
- 양쪽 모두 정규 시즌 중 주당 연습생 관리비 10만 원이 별도로 발생한다.
- 연습생이 프로로 데뷔할 때 기본 연봉은 3,000만 원 고정,
  계약 기간은 1~2시즌 협상이다.

4. 날짜·시즌 구조 [확정 — 2026-10-27 개정]
======================================================================
게임에 실제 YYYY-MM-DD 달력을 표시하거나 이를 내부 시즌의 기준으로 삼지 않는다.
표시 예시:
  시즌 1 · 정규 1주차 · 월요일
  시즌 1 · 포스트시즌 2주차 · 금요일
  시즌 3 · 비시즌 4주차 · 일요일

- 게임 내 1시즌(1년) = 정규 시즌 24주 + 포스트시즌 3주 + 비시즌 4주.
- 총 31주 × 7일 = 217일. 첫 게임 날짜는 반드시 시즌 1 · 정규 1주차 · 월요일.
- 요일은 월요일부터 일요일까지 7일 반복한다.
- 정규 24주차 일요일 다음 날은 같은 시즌 포스트시즌 1주차 월요일이다.
- 포스트시즌 3주차 일요일 다음 날은 같은 시즌 비시즌 1주차 월요일이다.
- 비시즌 4주차 일요일 다음 날은 다음 시즌 정규 1주차 월요일이다.
- 새 시즌을 위한 기존 인물 나이 증가·신규 인물 공개는 비시즌 1주차
  시즌 정산 때 처리한다. 동일 시즌에 두 번 나이 증가가 일어나면 안 된다.
- 입단·방출·이적·데뷔·은퇴·수상 및 게임 날짜 변경에는
  시즌/구간(정규·포스트·비시즌)/주차/요일을 저장한다.
- 개발 초기 테스트용 절대 일수는 내부적으로 사용 가능하지만 유저에게
  실제 연월일 형태로 표시하거나 컴퓨터 날짜를 참조하지 않는다.

정규 시즌 요일별:
월: 주간 상대·콘텐츠 확인, 1군/2군 명단 및 리더 선정, 계약·방출·트레이드
화: 일반 경기 없음
수: 정규 경기
목: 정규 경기
금: 정규 경기
토: 정규 경기 (주간 성장·2주마다 노화 정산은 월요일)
일: 정규 경기 또는 특별전 + 후원금 정산

- 4, 8, 12, 16, 20, 24주차 일요일은 특별전이다.
- 4주마다 급여 지급은 해당 주 일요일 활동 종료 뒤 정산한다.
- 월요일 정산은 지난주 월요일~일요일 활동을 집계한다.
- 24주차 일요일 기록은 정규 시즌 종료 전 별도 누락 없이 정산한다.
- 정규 경기 미처리 시 해당 날짜를 넘길 수 없다. 특별전 미처리 시도 동일.
- 드래프트 후 최초 선수단 편성·리더 지정이 미완료인 세이브는 첫날
  월요일에 관련 작업을 마칠 수 있도록 진행을 차단한다(버그 예방용 운영 원칙).
- 이미 진행한 날짜·선수단·드래프트 기록을 사용자 승인 없이 일괄 초기화하거나
  되감지 않는다. 잘못된 세이브는 백업 후 상태를 진단해 별도 복구한다.

포스트시즌 3주 [확정]:
- 정규 종료 다음 주 월요일: 필요한 동률 결정전 처리 및 순위 확정.
- 각 포스트시즌 주의 화요일: 참가 기획사 준비·대진 확인일.
- 수요일: 해당 라운드 1차전.
- 목요일: 2차전.
- 금요일: 양 팀 1승 1패인 경우에만 3차전. 먼저 2승이면 취소.
- 토·일요일: 해당 라운드의 추가 경기는 없다.
- 라운드: 1주차 정규 3위 vs 4위 / 2주차 정규 2위 vs 1R 승자 /
  3주차 정규 1위 vs 2R 승자. 매 라운드 3판 2선승.
- 금요일 3차전이 1승 1패로 확정되면 양측에 특별 1군·2군 교체 허용.
  별도의 '선수단 잠금' 버튼은 만들지 않는다. 경기 시작 시의 출전 명단을 사용.
- 포스트시즌 경기의 피로·부상은 일반적으로 기존 규칙을 적용한다.
  3연전이므로 같은 선수가 수·목·금 모두 출전하면 금요일 3일 연속
  출전 페널티(-10%)가 발생한다(직전 출전 상황도 일반 규칙대로 계산).
- 포스트시즌 성적은 정규 경기 117회, 정규 승점 및 정규 개인상 집계와 분리.
- 리그 최종 우승 기획사는 챔피언 트로피를 획득하며, 정규 1위는 별도 기록.

비시즌 4주 [확정]:
1주차: 시즌 정산, 시즌 종료 보너스, 기존 인물 가상 나이 증가,

- 비시즌에는 정규 경기, 일반 훈련, 성장·노화 정산, 후원금, 정기 급여 없음.

5. 정규 리그와 대진표 [확정 + 공정성 개선 채택]
======================================================================
- 기획사 10개가 경쟁한다.
- 각 기획사는 나머지 9개 기획사와 정확히 13번씩 맞붙는다.
- 기획사당 정규 경기: 9 × 13 = 117경기.
- 리그 전체 정규 경기: 10 × 117 ÷ 2 = 585경기.
- 정규 경기 가능일: 24주 × 수~일 5일 = 120일.
- 특별전 일요일 6일을 제외하면 일반 경기일 114일.
- 일반 경기일 114일 중 무작위 3일을 더블헤더로 선정한다.
  111일 × 기획사당 하루 1경기 + 3일 × 하루 2경기 = 117경기.
  리그 경기 기준: 111일 × 5경기 + 3일 × 10경기 = 585경기.
- 더블헤더 3일은 고정 주차가 아니며 한 주에 몰리는 것도 허용한다.
- 더블헤더 경기 순서는 1차·2차로 기록하고 같은 순서에서 한 기획사가
  동시에 두 경기에 배정되는 일은 없다.
- 승리: 리그 승점 +1, 패배: +0. 기본 정규 경기 무승부 없음.
- 개별 정규 경기 성공 횟수 동점은 해당 경기의 데스매치로 승패 결정.
- 특별전 승점은 특별전 규칙에 따르며 정규 585경기와 별도로 관리.

정규 리그 순위 동률 결정전 [확정 — 이전 복합 타이브레이커 대체]:
- 정규 시즌 종료 시 리그 승점이 같은 기획사들은 서로 겨뤄 순위를 가린다.
- 과거 규칙인 상대 전적 → 전체 성공률 → 최근 10경기 승률 → 무작위
  추첨 순위 결정은 사용하지 않는다.
- 동률 묶음마다 기존 정규 콘텐츠 30종 중 1종을 무작위로 뽑아 단판 대결.
- 2팀 동률: 동일 콘텐츠에서 양 팀이 단판.
- 3팀 이상 동률: 해당 팀 전원이 한 번씩 같은 콘텐츠·동일한 필요 출전
  인원으로 동시에 판정하여 성공 점수 순으로 그 그룹 내부 순위를 정함.
  기존 1:1 정규 경기와 별개인 '다자 순위 결정전'으로 취급한다.
- 점수마저 같은 팀은 동률 그룹 내 그 팀들끼리 주요 능력치 추가 판정을
  동등하게 실시하여 순서가 정해질 때까지 반복한다(한 번의 결정전 흐름).
- 결정전에서만 참가 아이돌의 '연속 출전 피로 페널티'를 0으로 간주한다.
  실제 선수의 누적 출전·1군 등록 기록을 영구 초기화하지 않는다.
- 기존 부상 상태는 유지하고, 숨겨진 잠재력·임의 능력 보너스 사용 금지.
- 정규 시즌 전적·승점 117경기 수에는 결정전 기록을 추가하지 않는다.
- 여러 팀이 동률일 때 결정전으로 1~10위 전체 순위를 확정하며
  특히 포스트시즌 1~4위 시드와 5위 경계에 적용한다.
- 개최 시점은 포스트시즌 1주차 월요일(필요할 때만)으로 운영.

일정 공정성 개선 [채택·구현 권장]:
- 위에 적힌 완전 대진(상대마다 13회), 585경기, 더블헤더 3일 및
  콘텐츠별 총량을 절대 우선하는 하드 제약으로 유지한다.
- 가능하면 각 기획사의 콘텐츠별 출전 횟수가 유사하도록 편차를 최소화.
- 주요 능력치 그룹(보컬/댄스/랩 등) 및 출전 인원(1~2·1~3·3~5·5명)
  분포의 편향을 줄여 특정 팀만 유리한 맵을 과도하게 배정받지 않도록 한다.
- 같은 상대와의 연속 맞대결·한 주에 여러 번 맞대결이 과도하게
  집중되지 않도록 소프트 제약을 적용한다. 불가능하면 하드 제약을 우선.
- 더블헤더 3일은 모든 기획사 동일 날짜이며, 같은 상대를 하루에
  2회 연속 만나는 편성은 가능한 한 피한다(강제 금지 아님).
- '균등화'가 무작위성 자체를 제거하거나 기존 확정 규칙과 충돌해서는
  안 된다. 구현 전후 콘텐츠 노출 횟수·반복 상대 간격을 통계로 검증한다.
- 경기 순서·출전 인원 범위의 실제 인원·특별전 종류의 공개 시점은
  해당 구간의 정보 제한 규칙을 준수한다.

7. 정규 경기 판정 시스템 [확정]
======================================================================

- 실제로 출전하는 아이돌 1명당 기본 능력치 판정 60회.
- 주요 능력치 30회 + 보조 능력치 30회.
- 주요 능력치가 2종이면 15회씩, 3종이면 10회씩 판정한다.
- 보조 판정의 능력치는 매회 남은 8개 능력치 중 주요 능력치 외에서
  무작위로 중복 허용 선택한다.
- 판정 성공 확률은 적용되는 해당 능력치 점수에 비례한다(0~100%).
  연속 출전 피로 페널티가 있으면 일시 적용 능력치가 낮아진다.
- 양 팀 출전자의 성공 횟수 총합이 큰 쪽이 이긴다.
- 기본 판정 60틱을 0.5초마다 갱신하면 약 30초 경기 연출이 된다.
- 건너뛰기(스킵)하면 같은 판정 결과를 즉시 처리한다.
- 해당 주 지정된 1군 리더가 출전 시 리더십 추가 판정 2회.
  경기 길이는 변하지 않으며, 이 판정 결과는 별도 기록한다.

정규 경기 동점 데스매치:
- 양 기획사에서 대표 아이돌 1명씩 선택.
- 각 대표가 그 맵의 주요 능력치로 10회씩 추가 판정한다.
- 계속 동점이면 10회 판정 묶음을 반복한다.
- 1묶음 연출 약 5초, 스킵 가능, 리더 추가 판정 없음.
- 5명 출전 맵은 지정 1군 리더를 대표로 사용하는 것이 기존 설계.

부상으로 인원이 부족할 때:
- 당일 건강한 1군만 출전시킨다. 2군 긴급 대체 출전은 금지.
- 5명 맵에서 1군 1명이 부상이라면 4 대 5로 실제 경기를 치른다.
- 필요한 인원이 3명인데 2명만 가능하다면 2명만 내보낸다.
- 출전 가능 인원 0명이면 몰수패.
- 양측 모두 출전 가능 인원 0명이면 양측 몰수패(둘 다 승점 0).
- 부상 관리 실패에 대한 불이익을 경기 결과로 감수하는 설계이다.

8. 특별전 [확정]
======================================================================

- 정규 시즌 4·8·12·16·20·24주차 일요일, 총 6회 개최.
- 매번 아래 3종 중 하나를 각 1/3 확률로 독립 무작위 선정한다.
- 같은 특별전이 반복되거나 시즌 중 아예 나오지 않을 수도 있다.

특별전 종류 / 주요 능력치:
① 대학축제           : 예능 / 외모 / 신체
② K-POP 페스티벌     : 보컬 / 댄스 / 랩
③ 아이돌 체육대회    : 리더십 / 예능 / 신체

- 리그 1~5위는 상위 그룹, 6~10위는 하위 그룹으로 나눠
  각각 5개 기획사가 겨루는 5자 대결을 치른다.
- 각 기획사는 건강한 1군 + 필요한 2군 선수를 합해 총 10명 출전.
- 출전 아이돌 1명당 주요 능력치 15회(3종 각 5회) +
  보조 능력치 15회 = 기본 30회 판정, 연출 약 15초.
- 1군 리더의 보너스 리더십 판정 +2회, 출전 2군 리더는 +1회.
- 5자 대결 동점이나 후속 4자 대결의 순위 동점은 해당 동률 팀들만
  주요 능력치 추가 10회씩 판정하여 순위를 가린다(필요하면 반복).

특별전 리그 승점:
상위 그룹 1위 +2점, 2위 +1점, 3위 0점,
상위 그룹 4·5위는 후속 4자 대결 진출.
하위 그룹 5위 -2점, 3·4위 0점,
하위 그룹 1·2위는 후속 4자 대결 진출.

후속 4자 대결:
- 상위 그룹 하위 2팀 + 하위 그룹 상위 2팀으로 진행.
- 정규 콘텐츠 30종 중 무작위 1종을 이용하여 해당 맵의 출전 인원에 맞춰 대결.
- 후속 4자 대결에서 하위 그룹 소속 팀이 1위면 +2점.
- 상위 그룹 소속 팀이 4위면 -2점.
- 그 외에는 추가 승점 변동 없음.

  보컬 / 댄스 / 랩 / 예능 / 외모 / 신체 / 지성 / 리더십

추가 값:
- 건강 0~100: 능력치와 별도이며 주로 부상 위험에 사용한다.
- 현재 실력(CA): 8개 현재 능력치의 산술평균.
- 숨겨진 개별 잠재력 상한: 8개 능력치 각각 성장 가능한 최대치.
- 숨겨진 평균 잠재력(PA): 개별 잠재력 8개의 산술평균.
- 성장 상한은 현재 능력치보다 낮게 생성하지 않는다.
- 1~3개 능력치에 강점을 가지는 등 같은 평균에서도 모습이 다르게 생성된다.

현재 능력치 유형의 등장 확률:
  특화형 50% / 균형형 30% / 극단적 특화형 20%

예: 평균 70이어도 보컬 90·댄스 85인 인물이 있을 수 있고,
모든 능력치가 68~72 정도인 균형형 인물도 있을 수 있다.
유형은 현재 능력치의 분산을 의미하며 숨겨진 잠재력을 공개하지 않는다.

시장가치는 실제 잠재력 상한을 절대로 사용하지 않고, 현재 보이는
8개 능력치와 나이만을 반영한다. 플레이어와 AI 모두 숨겨진
잠재력 수치를 확인할 수 없다.

10. 주간 성장·추가 성장·노화 [확정]
======================================================================

공통:
- 정규 시즌 월요일에 지난주 활동의 주간 성장 정산.
- 비시즌 4주는 성장·훈련·노화 정산 없음.
- 능력치는 기본적으로 0~100 범위이며 잠재력 상한을 넘지 않는다.

[1군 기본 성장]
- 해당 주의 개인 주요 능력치 판정 '성공 횟수'를 모은다.
- 성공이 가장 많은 능력치 1위: +1 시도 확률 min(100,(100-A)×3)%.
- 2위: +1 시도 확률 min(100,(100-A)×2)%.
- A는 현재 해당 능력치 점수이다.
- 위 두 능력치는 하락 후보에서 제외한다.
- 나머지 능력치 중 한 주간 사용/시도 횟수가 가장 적은 1·2위를 선정.
  1위는 A% 확률 -1, 2위는 (A/2)% 확률 -1.
- 해당 주에 부상을 입었거나 3일 이상 연속 출전했다면
  위의 '상승 판정 2회'가 취소되지만 감소 판정은 유지한다.
- 한 주 동안 1군 경기 출전이 전혀 없으면 무작위 서로 다른
  능력치 2개가 자동으로 각각 -1.

[2군 기본 성장]
- 매주 서로 다른 능력치 2개를 무작위로 선정하여 훈련 판정.
- 각 능력치에서 상승 (100-A)×2%, 하락 A/2% 등의 기존 독립 판정을
  진행한다. 상승·하락 판정의 중복 결과는 우선순위로 정리한다.
- 2군 기본 훈련비: 선수당 주 10만 원.
- 선택적 집중 훈련비: 선수당 주 15만 원 추가.
- 집중 훈련 대상으로 정한 능력치는 기본 (100-A)×2% 확률로 +1,
  코치가 강점이라고 힌트를 준 능력치라면 (100-A)×3.5% 확률로 +1.
- 집중 훈련에는 감소 판정이 없다.
- 2군 리더는 매주 리더십/2% 확률로 2군 선수(자신 포함) 1명의
  가능한 무작위 능력치에 +1을 부여할 수 있다.
- 특별전 출전 자체로 2군 기본 성장 판정이 추가되지는 않는다.

[연습생 기본 성장]
- 매주 서로 다른 능력치 4개를 무작위 선정.
- 각 능력치에 대해 (100-A)×1.5% 확률로 +1 판정.
- 연습생 일반 훈련에서 능력치 감소는 없다.

[잠재력 격차에 따른 '추가 성장' — 모든 신분 적용]
- D = 숨겨진 잠재력 8개 평균 - 현재 능력치 8개 평균.
- 매주 기존 성장 외에 2번의 독립적인 추가 성장 판정을 한다.

  D >= 30          : 판정당 50%
  20 <= D < 30     : 판정당 40%
  10 < D < 20      : 판정당 25%
  0 < D <= 10      : 판정당 10%
  D <= 0           : 추가 성장 없음

- 각 판정에 성공하면 개별 잠재력 상한에 도달하지 않은
  능력치 하나를 균등 무작위 선택하여 +1.
- 두 번 모두 성공하면 +2, 한 번 성공하면 +1, 모두 실패하면 +0.
- 두 판정에서 같은 능력치가 다시 선택될 수 있다(상한 도달 시 제외).
- 성장 확률에 별도의 나이 보정은 없다.

[노화 감소]
- 27세 이하: 노화 감소 없음.
- 28~29세: 2주마다 무작위 능력치 1개 -1.
- 30세 이상: 2주마다 서로 다른 능력치 2개 각 -1.
- 판정 주차: 정규 2·4·6·...·24주차 월요일(시즌당 총 12회).
- 노화는 기존 성장과 별도로 적용하며 능력치 0 아래로 내려가지 않는다.
- 연간 노화 감소 총합(성장 제외): 28~29세 12점, 30세 이상 24점.

[연속 출전 피로]
- 연속 출전 날짜 3일째: 그날부터 유효 능력치 -10%.
- 4일째: -20%, 5일째: -30% 등 날짜당 10%p씩 누적.
- 하루라도 출전하지 않으면 연속 기록이 초기화된다.
- 더블헤더 2경기는 출전 '날짜'로는 1일이지만 부상 판정은 매 경기 발생.
- 위 감소는 경기 중 일시 페널티이며 영구 능력치 하락이 아니다.

11. 부상과 로스터 불이익 [확정]
======================================================================

- 건강 수치는 정적인 부상 위험 지표이며 부상 때마다 자동으로 줄지 않는다.
- 기본 경기 중 부상 확률: (100 - 건강) × 0.01% (출전 경기당).
- 경기 없이 1군에 등록된 날: (100 - 건강) × 0.005%.
- 2군 소속 일일 부상 위험: (100 - 건강) × 0.01% / 3.

1군 연속 등록 주차에 따른 위험 배수:
  1~2주차: 1배
  3주차  : 10배
  4주차  : 20배
  5주차  : 30배
  6주차  : 40배 (이후 1주 증가 때마다 10배 추가)

- 부상 확률에는 위 배수를 적용하며 최댓값 100%.
- 연속 1군이 3주 이하였다면 2군에서 1주 완전 휴식 후 배수 초기화.
- 누적 1군 4주 이상이었다면 2군에서 2주 연속 쉬어야 초기화.
- 4주 이상 누적 후 2군 1주만 머물다 복귀하면 주차 단계가 이어진다.
- 부상자는 다음 주 화요일부터 회복 판정/복귀 가능 시점이 되지만,
  기존 1군 부상자는 다음 월요일에 2군으로 내려가며 그 다음 주는
  1군에 복귀할 수 없다. 이후 정식 월요일 변경으로 복귀 가능.
- 부상 주간에는 건강한 남은 1군 인원만 경기에 내보낸다.
  2군 긴급 교체 금지, 인원 부족 시 숫자에서 불리한 경기 진행.
- 1군 출전 가능 인원 0명이면 몰수패.
- 부상이어도 이미 발생한 계약 급여 지급 의무는 유지한다.

12. 계약·시장가치·드래프트 [확정]
======================================================================

최초 16라운드 드래프트:
- 후보 200명, 10개 기획사, 총 160명 지명(16명씩).
- 최초 1~3라운드 지명자는 실력 기준 1~2시즌 계약을 협상한다.
- 최초 4~16라운드 지명자는 기본 3,000만 원/1시즌 계약.
- 계약 협상은 최대 3번 제안, 모두 실패하면 FA 시장으로 이동한다.
- 초기 드래프트 종료 후 프로 16명 구성이 부족하면 FA로 보충한다.

이후 매년 '통합 드래프트':
- 비시즌 2주차 진행, 총 3라운드, 10개 기획사 최대 30명 지명.
- 전 시즌 순위 역순 스네이크:
  1R: 10위 → 1위
  2R:  1위 → 10위
  3R: 10위 → 1위
- 후보는 신규 70명과 미계약·방출·FA 상태의 기존 프로를 포함한다.
- 드래프트는 기본적으로 정보 제한/블라인드 방식.
  신규 후보의 이름·사진·나이를 볼 수 있지만 구체 능력치,
  잠재력, 코치 힌트는 지명 전 공개하지 않는 방향.
- 14~16세 신규 지명자는 협상 없이 연습생 자동 계약(연 1,000만 원).
- 17세 이상 신규 지명자 또는 기존 FA 지명자는 연봉/기간 협상.
- 최대 3차 협상 실패 시 지명권 소모, 재지명 없이 FA 시장에 남는다.
- 미지명 14~16세 인물은 자유계약 연습생으로 영입 가능.

현재 능력치에 따른 기준 시장연봉(잠재력 절대 미사용):
  단위 만 원
  A = 현재 8개 능력치 평균
  S = 현재 가장 높은 능력치 2개의 평균
  Y = 나이 보정(17~18세: 0, 19~22세: +200,
                 23~26세: -100, 27세 이상: -200)

  시장연봉 = clamp(3000 + 60×(A-50) + 20×(S-A) + Y, 3000, 6000)
  최종 기준 시장연봉은 100만 원 단위로 반올림.
  프로 데뷔 연습생 계약은 이 공식과 별도로 연 3,000만 원 고정.

직접 계약 협상 수락 확률(시장가치 대비 제안):
  -10% : 30%
   -5% : 50%
    0% : 80%
   +5% : 90%
  +10% 이상 : 100%
- 사이 구간은 확률 선형 보간 사용(권장 구현값).
- 거절되면 직전 제안 연봉을 5% 인상하여 재협상.
- 제안은 총 3회까지, 금액은 만 원 단위 반올림.
- 초기 낮은 제안(-10% 이하)의 하한 확률은 현재 30%로 처리하는
  구현 권장값이며, 정밀 구간 처리는 밸런스 테스트 대상.

FA 공개 경쟁:
- 다수 기획사가 입찰하면 최고 연봉 제안을 기준으로 경쟁.
- 새로운 최고 입찰 뒤 2일간 추가 입찰 창을 여는 기존 설계.
- 동액 최고 제안이면 원 소속 기획사가 우선, 모두 외부면 추첨.
- 기존 계약 기간은 1~2시즌 단위.

13. 방출·은퇴·트레이드 [확정]
======================================================================

[일반 중도 방출]
- 방출 이후 일반 월급 지급은 중단한다.
- 중도 방출 위약금 = '남은 기본 계약 급여'의 1/3.
- 위약금 총액을 만 원 단위로 반올림한다.
- 위약금은 즉시 일시불 또는 10주 분할 지급 가능.
- 분할 지급 중 시즌이 끝나더라도 이미 발생한 채무는 유지한다.
- 정상 만료에는 중도 방출 위약금이 없다.
- 프로였던 인물은 방출되어도 연습생으로 돌아갈 수 없다.

[은퇴]
- 소속 없이 2년 연속 드래프트 미지명·미영입이면 은퇴.
- 33세 이상 아이돌은 계약 해지·방출 시 은퇴.
- 33세 이상이 계약 만료 후 재계약에 실패해도 은퇴.
- 33세가 넘어도 계약을 정상 유지·갱신했다면 계속 현역 활동 가능.
- 은퇴 후 기록은 보존한다.

[일반 트레이드]
- 반드시 프로 아이돌 교환이 기본이다(프로 ↔ 프로).
- 더 가치가 낮은 프로를 보내는 측은 보상으로 현금 또는
  연습생을 추가해 협상을 맞출 수 있다.
- 프로↔프로 거래에 덧붙일 연습생은 최대 3명까지.
- 연습생↔연습생 또는 연습생만으로 이루어진 트레이드는 불가능.
- 월요일에 계약과 로스터를 최종 처리한다.
- 거래에 포함된 선수는 이전 계약 조건 및 잔여 기간 승계.
- 연습생은 이동해도 기존 유급/무급 신분 유지.
- 프로 16명 정원 및 상대 기획사의 자금·자리 제한은 준수.
- 현금 거래가 성사되면 약정 금액을 즉시 지급한다.
- 선수의 별도 거부권은 없다.

[트레이드 AI: 잠정 채택, 추후 조정 가능]
- 거래 가치 비중: 현재 경기력 50%, 나이/관찰된 성장 15%,
  계약 조건 20%, 기획사 선수단 적합도 15%.
- 숨겨진 실제 잠재력(PA)을 AI가 직접 읽어서 판단하지 않는다.
- 받는 가치 / 내주는 가치가 90% 미만이면 대부분 거절,
  90~99%는 특별한 이유가 있어야 검토, 100~109%는 협상·역제안,
  110% 이상이면 긍정적, 120% 이상이면 매우 적극적인 평가.
- 최대 3회 역제안/협상으로 시작하고 실제 시뮬레이션 후 조정한다.
- 우승 경쟁, 재건, 재정 상태, 부상자 수에 따라 같은 선수라도
  기획사별 평가가 달라질 수 있다.

14. 기획사 재정 [확정]
======================================================================

- 10개 기획사 모두 최초 자금 10억 원.
- 정규 시즌 주간 후원금: 기획사당 1,000만 원 × 24주 = 2억 4,000만 원.
- 시즌 종료 보너스: 성적과 관계없이 기획사당 10억 원.
- 승리할 때마다 추가 경기 상금을 주는 구조는 아니다.
- 대출·마이너스 잔액은 허용하지 않는다.
- 비시즌에는 정기 후원금·급여·기본 훈련비가 발생하지 않는다.

급여 지급:
- 정규 시즌 4·8·12·16·20·24주차에 총 6회 지급.
- 한 번의 기본 급여는 시즌 계약 연봉의 1/6을 기준으로 정산.
- 4주 중 실제 1군 활동 주차가 3주 이상이면 해당 지급분 +10%.
- 4주 중 2군 소속 주차가 3주 이상이면 해당 지급분 -10%.
- 부상 발생 자체만으로 이미 얻은 급여 보너스를 취소하지 않는다.
- 부상으로 강제 2군 이동한 주차는 2군 주차로 집계한다.
- 지급 금액은 만 원 단위 반올림, 마지막 회차에서 기본 급여 오차 보정.

운영 비용:
- 연습생: 1인당 정규 시즌 매주 관리비 10만 원.
- 2군 기본 훈련: 1인당 주 10만 원.
- 선택적 2군 집중 훈련: 1인당 주 15만 원 추가.
- 드래프트 출신 연습생: 연 1,000만 원, 자유계약 연습생: 연 0원.
- 프로 연봉은 계약에 따르며, 프로 데뷔 첫 계약은 연 3,000만 원.

[자금 부족]
- 먼저 신규 계약, 추가 영입, 선택적 훈련 등 재량 지출을 제한한다.
- 이미 확정된 급여·위약금 의무는 사라지지 않는다.
- 급여 지급 시 현금이 부족하면 미지급 급여를 '채무'로 기록하고
  리그 승점을 2점 차감한다.
- 이후 주간 후원금과 시즌 종료 보너스는 채무 상환에 최우선 사용.
- 그래도 채무가 부족하면 강제 선수 매각 절차를 시행한다.
- 강제 매각 대상은 프로 선수 중 연봉이 높은 순서로 자동 선정.
- 강제 매각 가격 = 해당 선수 '시즌 연봉의 1/2'.
- 구매자가 충분한 현금과 선수단 자리를 보유해야 실제로 성사된다.
- 매각 성사 즉시 대금 전액 선지급. 판매 기획사는 채무부터 상환.
- 강제 매각은 이적이므로 일반 방출 위약금은 발생하지 않는다.
- 매수 가능한 기획사가 없다면 거래를 허위로 성사시키지 않고
  채무를 유지한다.

[AI 재정 운영: 권장]
- 미래 급여·관리비·기존 채무를 고려한 지출 가능액을 계산한다.
- AI 기획사는 안정형/균형형/공격형 등 예산 위험 성향만 다르게 하고
  실력 판단에는 모두 동일한 규칙을 적용한다.
- 시즌 보너스 10억 원 때문에 장기 자금이 과도하게 누적되는지는
  10~20시즌 자동 시뮬레이션 후 점검한다.

15. 경기 개인 기록과 통산 기록 [확정]
======================================================================

매 정규 경기마다:
- 이긴 팀: 개별 능력치 이벤트 성공 횟수가 가장 많은 출전자 1명을
  '승리 아이돌'로 선정한다.
- 진 팀: 개별 능력치 이벤트 실패 횟수가 가장 많은 출전자 1명을
  '패배 아이돌'로 선정한다.
- 실제 출전한 경기 수만 '경기 수'로 기록한다. 단순 1군 등록은 출전 아님.
- 선수별 능력치 판정 시도/성공/실패를 주요·보조 구분하여 저장한다.
- 리더 보너스 판정은 일반 능력치 판정과 구분하여 기록한다.

선수별 관리 기록:
- 정규 경기 선발 출전 횟수, 출전 경기 팀 승·패, 승리/패배 아이돌 수상 횟수
- 전체 이벤트 성공률과 능력치별 성공률
- 30종 콘텐츠 각각의 출전 수·이벤트 판정 시도/성공/실패·성공률
- 시즌별 성장/감소 기록(기본 훈련, 추가 성장, 노화 등 원인별)
- 1군 등록 날짜 수
- 1군 실제 활동 주차 수(월급 인센티브 판정에 활용)
- 연속 출전 '날짜'와 최장 연속 출전 날짜 수
- 정규 경기와 특별전 기록 분리
- 모든 시즌을 합친 통산 기록
- 은퇴·이적 후에도 개인 통산 기록 보존

'콘텐츠별 성적' 화면 정렬:
- '성공률순' 또는 '출전 횟수순' 버튼으로 전환 가능.
- 성공률은 해당 콘텐츠에서 성공 판정 합계 / 시도 판정 합계.
- 출전 횟수는 실제 경기 선발 출전 건수.

16. 시즌 개인 시상식 [확정]
======================================================================

한 시즌에 개인상 총 11개:
  ① MVP
  ② 신인왕
  ③ 리더상
  ④~⑪ 보컬/댄스/랩/예능/외모/신체/지성/리더십 매력상

- MVP: 전체 프로 아이돌 중 '승리 아이돌' 선정 횟수 최다.
- 신인왕: '프로 데뷔 1년 차' 아이돌 중 승리 아이돌 선정 횟수 최다.
  (연습생이었던 기간은 신인왕 자격을 소모하지 않음.)
- 리더상: 1군 리더로 출전할 때 발생한 '추가 리더십 판정 2회'의
  성공 횟수 누적이 가장 많은 아이돌.
- 능력치별 매력상:
  1) 해당 능력치의 정규 경기 '판정 시도 횟수' 상위 5명을 선정.
  2) 그 5명 중 해당 능력치 '성공률'이 가장 높은 아이돌이 수상.
  3) 리더십 매력상 계산에는 1군 리더의 추가 2회 판정을 제외한다.
- 각 상에서 선정 기준 동률이면 최종 리그 순위가 더 높은
  기획사의 아이돌에게 수여한다.
- 같은 기획사 선수끼리도 동률이면 무작위 추첨으로 1명 선정.
- 신인왕·MVP 등 여러 상 동시 수상은 가능하다.
- 수상 시즌, 당시 기획사, 수상 기록은 개인 경력에 영구 누적한다.
- 게임 내 '연말시상식' 정규 경기 콘텐츠와 별도의 시즌 마감 시상이다.

17. 아이돌 프로필과 UI [확정 방향]
======================================================================

전체 UI 목표:
- 화려한 월드맵, 장시간 캐릭터 애니메이션보다 표·텍스트를 우선.
- 높은 가독성, Windows 맑은 고딕, 연한 파랑·화이트 파스텔톤.
- 왼쪽 세로 메뉴, 가운데 정렬 가능한 데이터 표, 오른쪽 선택 인물 프로필.
- 선수 사진은 직접 준비한 이미지 파일을 사용한다.
- 픽창/경기 대결실만 구분되는 별도 화면으로 만든다.

메인 메뉴 예시:
  기획사 홈 / 1군 / 2군 / 연습생 / 경기 일정 / 리그 순위 /
  드래프트·FA / 트레이드 / 재정 / 개인 기록·시상식 / 설정·저장

아이돌 기본 프로필 상단:
- 얼굴 사진, 이름, 현재 소속 기획사(로고 포함), 나이, 현재 신분
- 8개 능력치, 현재 평균, 건강, 특화 유형
- 연봉, 잔여 계약 기간
- 현재 기획사 입단일 / 최초 입단일 / 프로 데뷔일
- 이전 소속에서 현재 소속으로 이동한 이력, 예: 'SM → JYP'

프로필 5개 탭:
  1) 능력치: 8개 능력치·건강·소속·부상·1군 누적 주차
  2) 개인 기록: 시즌/통산 경기 수, 승리·패배 아이돌 선정 수,
     1군 등록 날짜, 활동 주차, 최장 연속 출전
  3) 콘텐츠 성적: 맵별 출전 횟수, 성공률 및 정렬 기능
  4) 성장 기록: 시즌·주차별 능력치 증감 및 증감 원인
  5) 계약·경력: 기획사 이동, 입단 날짜, 계약·연봉 변동, 수상 내역

기획사 이력 예시:
  시즌 1 · 창단 드래프트      : SM 최초 입단
  시즌 2 · 정규 14주차 월요일: SM → JYP (트레이드)
  시즌 3 · 비시즌 3주차      : JYP → FA → SM (자유계약)

- 과거 소속 이력을 덮어쓰지 않고 전체 이동 기록을 시간순 보존한다.
- 드래프트 지명 전에는 신규 후보의 현재 능력치와 잠재력 힌트를 숨긴다.
- 연습생·FA 자유계약 검토 시 코치가 성장 가능성이 돋보이는 능력치
  1~2개를 정성적으로 힌트로 줄 수 있다. 수치형 잠재력은 공개하지 않는다.

18. AI 기획사 운영 방향 [2026-10-27 채택·구현 권장]
======================================================================
핵심 철학:
- 다른 9개 기획사는 플레이어와 동일한 급여·부상·성장·계약·
  선수단 정원·승점·피로 규칙을 따라야 한다.
- AI만 실제 PA(숨겨진 잠재력 상한), 특별 유망주 내부 표식,
  향후 무작위 판정 결과, 미래 콘텐츠 비공개 정보에 접근하면 안 된다.
- 난이도 조절을 위해 AI에게 몰래 능력치/판정/재정 보너스를 주지 않는다.
- 같은 공개 정보를 활용한 더 좋은 판단으로 경쟁해야 한다.
- 유료 LLM API 없이 로컬 Python 규칙과 계산으로 작동한다.

A. 월요일 주간 1군 편성 [기존 능력 조합 평가를 개선]:
- 이번 주 공개된 상대·콘텐츠·더블헤더·특별전 일정을 확인한다.
- 1군 후보 5명 조합을 평가할 때 '현재 강점과 콘텐츠별 기대 성공 횟수',
  '다양한 콘텐츠 대응', '건강', '연속 1군 등록 주차에 따른 부상 위험',
  '2군에서 휴식할 필요', '향후 1~2주 운영 가능성'을 함께 고려한다.
- 무조건 현재 평균 능력치가 높은 5명을 매주 고정하지 않는다.
- 피로·부상 위험이 증가해도 순위 경쟁이 중요한 경우 제한적으로
  위험을 감수할 수 있다. 위험을 무조건 회피하지는 않는다.
- 숨겨진 잠재력을 직접 읽지 않는다. 육성 판단은 공개 나이,
  능력치, 관찰된 성장 기록, 코치의 정성적 평가에 한정한다.
- 장래 2~4주 단순 전망/몬테카를로는 계산 비용을 보아 선택 적용.

B. 경기일 출전자 결정:
- 해당 날짜에 공개된 실제 필요한 출전 인원(1~2/1~3/3~5 등)을 확인한다.
- 1군의 출전 가능 선수만 대상으로, 콘텐츠 주요 능력치와 남은 보조
  능력치의 기대 판정 성공 수를 함께 계산한다.
- 매 경기마다 연속 출전 날짜·해당일 피로·부상/컨디션을 적용한다.
- 향후 그 주의 공개된 경기도 고려하여 에이스 출전을 분산할 수 있다.
- 더블헤더에서는 첫 경기 출전자와 두 번째 경기의 선수 활용을 함께
  최적화한다. 두 경기라도 출전 '일수'는 하루로 계산한다.
- 경기일 이전에는 실제 확정 인원이나 판정 난수, 상대의 비공개
  로스터 선택을 미리 읽을 수 없다.

C. 리그 순위에 따른 전략 조정:
- 1~4위 포스트시즌 진출·1위 결승 직행·2위 2R 직행이라는 가치 반영.
- 4위/5위 경합, 1위/2위 경합에서는 승리 확보 가중치를 높일 수 있다.
- 남은 경기·특별전에서 얻거나 잃을 수 있는 승점을 함께 고려해야
  '순위 확정'을 판단할 수 있다. 단순 현재 승점만으로 단정 금지.
- 순위를 수학적으로 확보했거나 포스트시즌 직전이라면 핵심 선수의
  부상 위험을 줄이는 전략을 선택할 수 있다.
- 포스트시즌 1승 1패 금요일 3차전 교체 권한은 AI에게도 동일 부여.
  상대에게 공개되지 않은 내부 PA나 미래 판정 결과를 이용하지 않는다.
- 탈락/비진출 AI도 선수 관리·계약·육성에 동일 제약을 지킨다.

D. AI 운영 성향(능력치 보너스가 아닌 평가 가중치 차이):
- 안정형: 부상·자금 위험을 상대적으로 강하게 회피.
- 균형형: 현재 승리 기대와 선수 육성·휴식의 균형.
- 공격형: 우승권 또는 포스트시즌 경쟁에서 즉시 전력·위험 감수 비중 증가.
- 성향은 기획사명과 무조건 결부하지 않아도 되며 새로운 세이브에서
  배정할 수 있다. 정확한 수치 가중치/분포는 시뮬레이션으로 검증.
- 공통 기준(공개 정보, 규칙, 계산 결과)은 동일하며 실행 전략만 다름.

E. 선수 영입·계약·재정:
- 비시즌 3라운드 드래프트, FA, 프로 데뷔, 재계약, 트레이드,
  중도 방출, 2군 집중 훈련을 장기 자금과 선수단 제한에 따라 판단한다.
- 선수 평가는 현재 경기력, 나이, 관찰된 성장, 계약 비용,
  포지션/콘텐츠 적합성 위주. 실제 PA 사용 불가.
- 기존 트레이드 잠정 평가(현재 경기력 50%·나이/성장 15%·계약 20%·
  선수단 적합도 15%)는 후속 밸런스 테스트에서 조정 가능.
- 급여·관리비·기존 채무를 반영해 미래 지출을 계획한다.

F. 검증 원칙:
- 10개 AI 자동 다수 시즌 테스트에서 순위, 성향별 승률, 1군 교체
  빈도, 장기 등록 부상, 맵별 강팀 승률, 자금 잔액, 성장 등을 관찰.
- AI가 전승하거나 특정 성향만 지속적으로 승리한다면 내부 평가
  가중치를 수정하되 숨겨진 보너스를 주지 않는다.

  자동 테스트를 둔다. 실제 PA 조회 경로를 테스트로 금지한다.
- 계산량 폭증 시 조합 탐색/2~4주 전망의 깊이를 축소하거나 캐시 적용.
- AI가 플레이어보다 실력이 좋은 판단을 하게 하되 규칙상 특권은 없다.

21. 정규 순위 동률 결정전 상세 운영 [확정 + 세부 운영 정리]
======================================================================
1) 순위가 정규 24주 종료 후 결정되며, 특별전 증감 승점까지 반영한다.
2) 동률 점수 그룹끼리만 하나의 결정전 그룹을 형성한다. 동률이 없는
   기획사는 결정전에 참가하지 않는다. 그룹별 서로 다른 무작위 콘텐츠.
3) 2팀인 경우 기존 1:1 정규 경기의 능력치 판정 규칙을 사용한다.
4) 3팀 이상인 경우 기존 콘텐츠 30종 중 같은 1종을 뽑아 모든 참가
   기획사가 같은 맵의 동일 출전 인원 기준으로 함께 판정한다.
   이는 일반 정규 1:1의 경기 편성 제한과 별개인 특별 순위 결정전이다.
5) 출전자가 부족하면 일반 정규 경기의 결원·몰수패 규칙을 적용한다.
6) 피로 '싹 없앰'은 이 순위 결정전 계산에 한정한다. 실제 누적 데이터
   삭제는 금지하되, 이 경기의 유효 능력치에는 피로 감소를 적용하지 않는다.
   실제 부상 선수는 건강한 선수로 간주하지 않는다.
7) 기본 판정 결과 동률 점수인 팀들만 해당 맵 주요 능력치를 이용한
   추가 10회 판정(출전 팀별 동일 횟수)으로 우열을 반복 결정한다.
8) 정규 승점/승패/개인상/주간 훈련 기록과 결정전 기록은 분리한다.
9) 결과는 시즌 N의 최종 정규 순위 표에 연결하고, 포스트시즌 진출
   1~4위 및 1·2위 시드를 확정한다. 같은 동률 그룹 처리 중 화면·DB의
   임시 순위를 '최종'으로 오인하지 않도록 한다.
10) 1승 1패/3판 2선승과 혼동하지 않는다. 동률 결정전은 단판이다.

22. 포스트시즌 3주·챔피언 트로피 상세 [확정]
======================================================================
정규 시즌 종료 시 승점 및 순위 결정전으로 1~10위를 최종 확정한다.
정규 1위 자체는 공식 기록이지만 우승 트로피는 별도 포스트시즌 우승자만 받는다.

포스트시즌 1주차: 정규 3위와 4위가 3판 2선승으로 대결.
포스트시즌 2주차: 정규 2위와 1주차 승자가 3판 2선승으로 대결.
포스트시즌 3주차: 정규 1위와 2주차 승자가 3판 2선승으로 대결.

매 라운드의 공통 일정:
- 월요일: 일반 월요일 운영. 첫 주는 필요 시 정규 동률 결정전을
  같은 월요일에 마친 후 최종 시드 확정.
- 화요일: 포스트시즌 준비일. 대진 및 경기 콘텐츠·상대 확인.
- 수요일: 시리즈 1차전.
- 목요일: 시리즈 2차전.
- 금요일: 1승 1패라면 3차전, 2승 0패/0승 2패면 미개최.
- 토요일과 일요일: 포스트시즌 추가 정규 시리즈 없음.
- 수·목·금 3연전은 연속 출전 피로·부상을 포함한 운영 실력을 시험.
- 각 시리즈의 콘텐츠는 기존 정규 30종 중 선정하며, 정규 판정과
  동점 데스매치·출전자 수 규칙을 재사용한다. 선정 알고리즘의 세부
  배분은 확정된 기존 정보 공개 규칙을 해치지 않는 범위에서 운영.
- 일반 경기 585건 및 정규 승점·정규 콘텐츠 19/20회 배분에
  포스트시즌을 합산하지 않는다.

금요일 3차전 특별 로스터 변경:
- 해당 시리즈가 1승 1패일 때만 양 참가 기획사에게 허용.
- 기존 1군·2군 프로 중 맞교환 가능. 1군 5명, 프로 최대 16명 유지.
- 평소 월요일 제한에 대한 예외일 뿐, 연습생 긴급 데뷔·FA 신규 영입
  또는 부상 무효화 권한을 주지 않는다.
- 1군 리더가 내려가면 기존 리더 소속 일관성을 유지하고 새 리더 지정.
- '선수단 잠금'이라는 별도 버튼·확정 단계는 필요 없다.
- 단, 이미 시작된 경기의 출전자/경기 판정 기록은 중간에 바꿀 수 없다.
  경기 시작 순간 그 경기에 출전하는 선수 명단은 정상적으로 기록한다.
- 금요일 교체는 경기가 시작되기 전까지 가능하며, AI도 동일 권한을 가짐.
- 교체는 자동 원복하지 않고 현재 선수단 상태로 유지하는 방향을 사용.

시리즈 종료 및 트로피:
- 한 기획사가 먼저 2승에 도달하면 즉시 종료, 3차전이 필요 없으면 취소.
- 결승 시리즈 최종 승자에게 시즌 N의 '챔피언 트로피' 1개 수여.
- 정규 시즌 1위, 포스트시즌 진출, 라운드별 승패 및 통산 우승 횟수 저장.
- 과거 시즌 우승 당시 기획사와 선수 경력 기록은 영구 보존.
- 2~4위 시드 우대는 진입 라운드 차등 자체로 주어지며,
  별도 숨겨진 능력치 보너스나 1승 어드밴티지는 부여하지 않는다.
- 탈락/비진출 플레이어는 다른 팀의 플레이오프를 관전하거나
  시리즈를 실제 계산하면서 빠른 진행 가능하도록 개발 권장.

24. AI가 같은 조건에서 더 좋은 결정을 하는 기준 [채택·구현 권장]
======================================================================
A. 공개 정보 경계:
- 최초 창단 및 신인 블라인드 드래프트: 이름·사진·나이만 보고 지명.
- 기존 FA, 계약, 프로 거래: 게임이 합법적으로 공개한 능력치,
  경기 기록, 나이, 관찰된 성장, 계약 조건 및 코치 힌트만 활용.
- 실제 PA, 비공개 특별 유망주 표식, 앞으로 공개할 맵·출전 인원,
  난수 생성 결과는 AI 평가 입력에 포함하면 안 된다.
- 모든 AI 정책은 동일한 경기/로스터/계약 검증 API를 호출한다.

B. 1군 월요일 조합 최적화:
- 이번 주 콘텐츠별 기대 판정 성공 수와 5명 조합의 다양성을 평가.
- 연속 1군 등록 위험 배수와 건강, 출전 날짜 피로, 2군 휴식 기간 평가.
- 휴식 선수를 교체할 때 당일 승률만이 아니라 주간·다음 주 안정성 확인.
- 해당 주 특별전이 예정되어 있으면 1군·2군 10명 활용 계획도 고려.

C. 매 경기 출전자와 위험 관리:
- 실제 필요 인원 확정 후 가장 효율적인 건강한 1군 인원을 선택.
- 기대 성공 계산은 주요 판정 + 보조 판정 모두 고려한다.
- 리더가 출전하면 +2 리더십 추가 판정 효과를 포함해 비교한다.
- 특정 선수의 연속 출전 3일째 -10%, 4일째 -20% 등을 적용.
- 경기 스킵·관전과 무관하게 판정 난수 결과 동일.
- 긴급 2군 대체 불가, 인원이 부족하면 적은 인원으로 경기.
- 포스트시즌 3차전 특별 1군 교체는 사람/AI 모두 동일 규칙.

D. 순위 기반 의사결정:
- 포스트시즌 1위 결승 직행 / 2위 2R 직행 / 3·4위 1R 진출 목표.
- 4위/5위 접전과 1위/2위 접전 시 단기 승률의 가중치 강화.
- 시드 확보 가능성은 남은 일정·특별전 승점 위험 포함해 판단.
- 순위 확정 시 무의미한 위험을 줄이고 포스트시즌 준비.
- AI는 '최종 순위 동률 결정전' 및 포스트시즌 우승 조건을 이해해야 함.

E. AI 성향과 밸런스:
- 안정/균형/공격 성향은 기대 성과·부상/재정 위험의 평가 가중치 차이.
- 특정 회사 이름에 특정 현실 특성을 주장하지 않으며 게임 내 가상 성향.
- 결과가 한 성향에 치우치면 수치 가중치를 조정하고 공개 능력치와
  동일 규칙 아래 경쟁할 것. 무작위 승패 조작/보정/숨겨진 버프 금지.
- 계산량이 과도하면 조합 탐색을 단순화하되 AI만 미래 정보 접근 금지.

F. 추천 자동 시뮬레이션:
- 경기/시즌 엔진 후 10~20시즌 × 여러 난수 시드를 반복.
- 기획사별 정규 승점, 콘텐츠별 승률, 포스트시즌 우승 비율,
  핵심 선수 부상률, 1군 교체 빈도, 육성, 재정/채무, 고착화 감지.
- 전력 균등한 10팀으로 시드 불평등이 없는 기준 시뮬레이션도 실행.

25. 플레이 가능한 기본 흐름 및 현재 구현 현황 [기획/개발 구분]
======================================================================
목표 플레이 흐름:
1) 사람 사진 DB 스캔 → 세이브 생성 → 플레이어 기획사 선택.
2) 초기 후보 200명 중 160명 16R 스네이크 드래프트(AI 9팀 참가).
3) 기획사별 프로 16명 확보 → 1군 5명/2군 11명 최초 편성 →
   1군/2군 리더 지정 → 시즌 1 정규 1주차 월요일 확정.
4) 월요일에 주간 일정과 공개 정보를 보고 로스터·리더 관리.
5) 수~일 정규 경기, 특별전, 일요일 정산, 월요일 성장·노화 정산 등.
6) 정규 24주 종료 → 승점 동률 결정전 → 최종 시드 1~4위 확정.
7) 포스트시즌 3주(3위 vs 4위 → 2위 → 1위, 수목금 3판2선승).
8) 우승 트로피 수여, 개인 시상 및 시즌 경력 기록.
9) 비시즌 4주(정산·신인 70명·3R 드래프트·FA·연습생 데뷔).
10) 다음 시즌 정규 1주차 월요일, 이후 다년간 반복.

최근 프로젝트 개발 이력(기능별 존재 여부; 완전 검증/안정화와 별개):
- 아이돌 사진/가상 능력치·잠재력/건강 생성: 구현됨.
- 기획사 10개, 스키마 마이그레이션 및 기존 데이터 보호: 구현됨.
- 최초 스네이크 드래프트 16R/160지명, 플레이어+AI: 구현됨.
- 1군/2군 최초 편성, 교체, 리더 지정: 구현됐으나 최근 회귀 오류 신고.
- 24주 정규 + 4주 비시즌 날짜 및 585정규경기·6특별전 일정: 구현됨.
- 31주(포스트시즌 포함) 날짜·리그 동률전·포스트시즌 스케줄:
  이번 기획서에서 규칙만 확정. 기존 프로그램에 구현 완료되었다는 뜻이 아님.
- 경기 판정·승패·개인 기록, 장기 성장/부상/계약·FA·재정·은퇴·시상:
  설계는 있으나 구현 완료로 간주하지 않음.

보고된 회귀 버그(해결 확인 전):
- 시즌 1 정규 1주차 수요일인데 1군 0/5, 2군 0/11 상태로 남고,
  5명 선택 후 최초 편성 확정 및 리더 지정이 막히는 현상.
- 경기 미처리 5건 때문에 날짜 진행까지 차단되는 교착 상태.
- 초기 날짜는 첫날 월요일이어야 하며 최초 선수단 편성을 마치기 전
  일자 진행이 허용되면 안 됨. 기존 세이브는 백업 후 개별 원인 수정.
- 최신 실제 PC 코드에서 해결되었는지는 사용자 실행으로 재확인 필요.

데이터/기록 보호 원칙:
- SQLite 세이브, 원본 사진, 드래프트, 기획사, 현재/잠재 능력치,
  연봉·소속·경력·일정·선수단 기록은 사용자 동의 없는 초기화 금지.

27. 초기 설계의 보충 기록 — 최신 기획서 누락 항목 [일부 재확인 필요]
======================================================================
이 절은 2026-10-26 통합본 0~20장에는 자세히 수록되지 않았으나,
프로젝트 초기에 논의되었던 게임 규칙을 누락 없이 추적하기 위한
참고 영역이다. 현재 1~26장의 최신 확정 규칙과 충돌하면 최신 규칙이
우선한다. 여기 적었다고 해서 모두 즉시 구현 대상으로 확정된 것은 아니다.

A. 코치 3명 설계 [과거 채택]:
- 1군 코치, 2군 코치, 연습생 코치를 각 1명씩, 총 3명 둔다.
- 주된 역할은 선수의 숨겨진 잠재 성장 가능성을 평가하는 것.
- 수치·범위로 실제 PA를 공개하지 않고, 능력치별 강점/성장 가능성을
  서술형(정성적) 힌트로 알려 준다.
- 지도자별 추가 능력치 버프나 코치 레벨/훈련 시설은 별도 확정되지 않았다.
- AI도 같은 코치 평가 원칙을 적용하며 실제 PA 수치를 직접 읽지 않는다.

B. 스캔들/논란 시스템 [과거 설계에 있었으나 현행 적용 여부 재확인 필요]:
- 프로에만 적용하고 연습생은 제외하던 구상이다.
- 일일 사건 확률 = (100 - 지성) × 0.001%.
- 리더십 80 이상이라면 위험 확률 1/2.
- 2군 소속이면 위험 확률 × 2/3. 두 완화 조건은 중첩 가능.
- 과거 설계의 등급별 비율: 하 60%, 중 30%, 상 10%.
- 사건 발생 시 8개 현재 능력치에 하 -10%, 중 -25%, 상 -50% 감소를
  적용하는 구상이었고, 능력치는 이후 정상 성장으로만 회복하도록 했었다.
- 2026-10-26 최신 통합 기획서에서는 해당 기능이 상세 규칙에서 빠졌다.
  따라서 '현행 확정'이 아니라 과거 설계 참고로 보관하고,
  별도 재확인 없이는 개발/시뮬레이션에 자동 도입하지 않는다.
- 실존 인물의 실제 행동·사건과 무관한 가상 게임 판정으로만 취급한다.

C. 초기 선수단 선발 설명 [최종 기준은 3장·12장·25장]:
- 창단 드래프트 16R로 10팀 각각 16명 지명(총 160명), 미지명 40명 FA.
- 창단 후보의 능력치·잠재력 비공개, 지명 완료 후 현재 능력치만 공개.
- 초기 1군 5명·2군 11명, 1군/2군 리더 각각 1명.
- 선수의 사진/이름과 8개 실력 수치는 전부 게임 속 가상 정보이며
  사진 속 실존 인물의 실력·나이·성격 등에 대한 평가가 아니다.
