# 19차 계약·FA·트레이드·방출·프로 데뷔 개발 보고

## 적용 기준과 사용 방법

기준은 마스터 기획서 3·4·12·13·14장과 19차 요청서입니다. 이번 대화에서 추가로 확정한 규칙은 다음과 같습니다.

1. **기존 만료 미정 계약은 유지**합니다. 새 시장 계약만 1~2시즌 만료를 적용합니다.
2. 기간 중 이적·계약 변경 급여는 **해당 4주 계약 유효일수/28일**로 나눕니다. 과거 미지급 채무는 원 기획사가 부담합니다.
3. 방출 위약금 10주 분할은 **다음 월요일부터** 시작합니다. 포스트시즌·비시즌에도 이미 확정된 지급 의무는 유지합니다.
4. FA의 새 최고 입찰 후 2일 창이 비시즌 3주차를 넘으면 **시장 마감 시 함께 종료**합니다.

실행 중인 게임을 완전히 종료한 뒤 프로젝트 `실행하기.bat`으로 다시 실행합니다. 왼쪽 **선수 시장**을 엽니다. 기존 세이브를 새로 만들 필요가 없습니다. UI는 플레이어 기획사만 조작하고 다른 기획사는 상대/조회 대상으로 표시합니다.

- FA 시장: 사진·이름·나이·신분·이전 팀·공개 CA/고정 추정 범위·기준 연봉·최고 입찰·기간·낙찰 상태. 연봉은 만원 단위, 기간은 1~2시즌입니다. 공개 입찰과 허용된 월요일 결원 직접 협상을 구분합니다.
- 계약 협상: 협상 개시 후 별도 확정 버튼으로 제안합니다. 열람만으로 수락 판정을 하지 않습니다. 잔여 시도·직전 제안·결과를 저장합니다.
- 트레이드: 양쪽 사진·프로·추가 연습생 선택, 부상·건강·나이·현재 능력치·강점·연봉·잔여 기간, 현금 조정, 제안/응답 이력. 양수 현금은 우리→상대, 음수는 반대입니다.
- 재계약: 소속 선수 선택 후 재계약 협상 버튼을 사용합니다.
- 방출: 즉시/10주 분할 선택. **확정 전에 위약금 총액을 안내**합니다. 채무 강제 매각 버튼도 이곳에 있습니다.
- 연습생: 14~16세 자유계약 영입 또는 17세 이상 소속 연습생 데뷔 협상.
- 거래 기록: 날짜·선수·이전/새 팀·당시 연봉·현금·위약금·연관 ID.

사진/이름은 기존 공통 프로필에 연결됩니다. 새 표도 도킹·분리·열 크기 저장 기능을 사용합니다. 역제안을 선택하면 실제 선수·현금·연습생 조건이 입력란에 반영되고, 수락 확인 창에도 해당 조건을 표시합니다.

## 3. DB 13 구조와 마이그레이션

새 테이블 15개:

| 테이블 | 역할 |
|---|---|
| market_runtime | 시장 도입 일수 |
| market_terms | 계약 시작·종료 시즌, 계약 승계 root |
| market_careers | 프로 데뷔 시즌, 이전 소속, 무소속 시작, 은퇴일 |
| market_days | 날짜별 시장 처리 중복 방지 |
| market_negotiations / market_offers | 협상 맥락, 상태, 1~3회 제안, 확률·seed·결과 |
| market_auctions / market_bids | 기한, 원 소속, 공개 입찰, 낙찰·추첨 결과 |
| market_trades / market_trade_versions | 제안·역제안 최대 3차, 합의 대기·완료·실행 불가 |
| market_history | 선수별 계약·이동·방출·은퇴 이력 |
| market_release_plans / market_installments | 확정 위약금과 10회 지급 기록 |
| market_draft_rights / market_draft_outcomes | 20차 연간 드래프트가 호출할 지명권/결과 연결 |

18차 `finance_contracts`, `finance_settlements`의 열과 기존 행은 유지합니다. 같은 날 계약을 두 번 승계할 때 이전 구간이 0일일 수 있도록 계약 구간 제약을 확장하고, 정산에 `market` 유형을 추가했습니다. 부모 테이블의 제약 확장은 **백업 후 하나의 마이그레이션 트랜잭션에서 행을 모두 복사해 교체**합니다. 외래키 검증을 끝낸 뒤 커밋하며 실패하면 원래 테이블·데이터·버전으로 롤백합니다. 이후 일반 연결은 외래키 검증을 켭니다.

정규 주간/보너스 정산의 고유 제약은 유지하고, 시장 거래는 고유 거래 ID를 씁니다. 기존 계약 연봉, 현금, 급여, 채무는 마이그레이션으로 다시 계산하지 않습니다. 이미 개발 도중 DB 13을 연 저장에서 검색 인덱스가 없으면 다음 실행 때 별도 백업 후 인덱스만 추가합니다.

## 4~5. 시장연봉과 직접 협상

정확한 공개 CA의 8개 평균 A와 상위 2개 평균 S를 사용합니다. 건강·PA는 넣지 않습니다.

`clamp(3000 + 60×(A−50) + 20×(S−A) + Y, 3000, 6000)`만원을 100만원 단위 사사오입합니다. Y는 17~18세 0, 19~22세 +200, 23~26세 −100, 27세 이상 −200입니다.

제안 비율 −10/−5/0/+5/+10%의 수락 확률은 30/50/80/90/100%, 중간은 선형 보간, −10% 이하 하한 30%입니다. 만원 단위 제안, 거절 뒤 5% 이상 인상, 최대 3회입니다. 협상 맥락과 횟수를 저장하여 재실행으로 초기화되지 않습니다.

실제 확정 때만 seed와 roll을 생성·저장합니다. 동일 요청 ID 재호출은 저장된 결과를 읽으며 계약을 다시 체결하지 않습니다. 계약 연봉 전체를 즉시 출금하거나 계약금·수수료를 만들지 않습니다.

미계약 신규 후보는 UI와 AI에서 **기존 5칸 추정 범위**를 사용합니다. 실제 기준연봉이 공개되지 않은 후보의 직접 협상 수락 확률도 UI에서 비공개입니다. 계약 판정 내부에서만 실제 CA 기준을 사용할 수 있습니다. PA는 어느 쪽에서도 읽지 않습니다. 기존 공개 선수는 실제값을 사용합니다.

## 6. 재계약과 만료

신규 계약은 일반적으로 정규 시즌 체결 시 해당 시즌부터, 비시즌 체결 시 다음 정규 시즌부터 1~2시즌입니다. 약정 마지막 시즌의 비시즌 1주차 동안 재계약 기회를 주고, 2주차 시작에 미재계약 선수를 FA로 전환합니다. 33세 이상이면 이때 은퇴합니다. 진행 중 재계약을 조용히 무시하지 않고 협상 완료/포기 전 날짜 진행을 차단합니다.

기존 만료 미정 계약은 사용자의 선택대로 **자동 만료시키지 않습니다**. 해당 선수를 새로 유한 기간 재계약하면 이후 그 계약에 만료 규칙이 적용됩니다.

## 7~8. FA 공개 경쟁과 기한

새 최고 연봉 뒤 게임 날짜 기준 2일 창을 적용하고 재실행으로 늘리지 않습니다. 동액은 기한을 새로 늘리지 않습니다. 비시즌 3주차 종료 시 남은 창도 함께 끝냅니다. 마감 후 신규 입찰은 거절하고 마감 처리만 수행합니다.

최고 연봉이 우선이며 동액이면 원 소속 우선, 외부 기획사끼리는 저장한 seed로 균등 추첨합니다. 낙찰 직전에 현금·채무·기존 급여·다른 입찰 약정·프로/2군 자리를 재검증합니다. 부적격 최고 입찰은 사유를 기록하고 다음 유효 입찰을 검토합니다. 유효 구매자가 없으면 FA로 유지합니다.

입찰 자체는 출금하지 않습니다. 여러 FA 입찰의 계약 예산과 자리를 함께 예약 검증하고, 최종 계약도 다시 검증합니다. 직접 협상을 먼저 열었더라도 공개 입찰이 시작되면 그 직접 제안으로 경쟁을 우회할 수 없습니다.

## 9~12. 트레이드·AI 평가·계약 승계·선수단

프로 1명↔프로 1명 교환이 필수이며, 현금과 양측 합계 최대 3명 연습생을 보상으로 붙일 수 있습니다. 연습생만/현금만/다른 팀 선수/중복 선수 거래는 차단합니다.

제안·역제안은 최대 3차. 합의가 월요일 이전이면 소속을 바꾸지 않고 대기합니다. 월요일에 계약·소유권·현금·정원·준비 경기 여부를 다시 확인하여 실행하거나 사유와 함께 실행 불가로 기록합니다. 이미 완료된 거래를 재실행하지 않습니다. 제안 이후 계약 조건이 바뀐 경우도 새 승계로 조용히 진행하지 않습니다.

AI 평가 비중은 경기력 50%, 나이/관찰 성장 15%, 계약 20%, 선수단 적합 15%입니다. 공개 현재 CA와 과거 일반 판정 성공률, 건강·부상, 공개 관찰 성장, 실제 연봉·잔여 기간, 팀의 약한 능력 구성을 사용합니다. 숨겨진 CA·PA·미래 RNG를 사용하지 않습니다.

90% 미만은 거절, 90~99%는 연봉 절감과 전력 필요를 함께 충족한 경우에만 검토합니다. 100~109%는 역제안을 우선하고 마지막에는 합의할 수 있습니다. 110% 이상은 긍정 평가입니다. 불리한 거래의 예외 수락도 공개된 연봉 절감/필요가 모두 있는 마지막 제안에 한정하는 결정적 정책이며, 새 수락 확률표를 만들지 않았습니다. 세부 점수 정규화는 `market_rules.py`에 분리했습니다.

승계는 이전 급여/채무 행을 고치지 않고 이전 기획사 부담 구간을 닫아 새 기획사 계약 구간을 생성합니다. root로 원 계약 연봉·시작 시즌·잔여 종료 시즌을 보존합니다. 과거 미지급은 원 팀 채무로 남습니다. 실제 CA·PA·나이·건강·부상·경기 결과는 바꾸지 않습니다.

프로 정원 16, 1군 최대 5, 2군 최대 11을 DB/서비스에서 검사합니다. 교환은 양쪽을 같은 트랜잭션 안에서 임시 분리한 뒤 각 팀의 빈 역할에 배치합니다. 떠난 리더는 해제합니다. 부상·복귀 제한 선수를 1군으로 배치해야 하는 경우 정상 대체 배치가 안 되면 거래를 차단합니다. 준비/진행 중 경기의 확정 출전자를 바꾸는 이동도 차단합니다. AI는 월요일에 부족한 1군 자리를 공개된 출전 가능 2군으로 보충합니다.

## 13~14. 방출과 10주 위약금

남은 **기본 계약 급여/3**을 만원 단위 사사오입합니다. 활동 보너스·기존 미지급을 위약금에 더하지 않습니다. 즉시 지급은 현금 확인 후 출금합니다. 분할은 총액을 확정 채무로 기록하고 다음 월요일부터 10회 지급합니다. 마지막 회차에서 반올림 오차를 맞춥니다.

아직 지급일이 안 된 분할금과 이미 연체된 채무를 구분합니다. 후원금이 들어왔다고 10주 계획 전체를 임의 선결제하지 않지만, 이미 연체된 분할금은 다른 만기 채무처럼 우선 상환합니다. 시즌 경계를 넘어도 의무와 지급 횟수가 남고 중복 출금하지 않습니다. 부족한 회차는 채무를 보존하며 급여 미지급 -2점과 혼동하지 않습니다.

일반 방출은 월요일에 프로를 FA로, 33세 이상을 은퇴로 전환하고 미래 급여 구간을 닫습니다. 이미 확정된 미지급은 삭제하지 않습니다. 정상 만료에는 위약금이 없습니다.

**기존 만료 미정 계약의 잔여 총급여는 확정할 수 없습니다.** 이를 임의로 1년이라고 가정하여 방출 위약금을 만들지 않습니다. 서비스가 이유를 안내하고 차단하며, 비시즌 1주차에 유한 기간 재계약을 확정한 뒤 일반 방출할 수 있습니다. 강제 매각은 원 계약을 그대로 승계하므로 만료 미정 계약도 거래 가능합니다.

## 15. 연습생 영입·데뷔·은퇴

14~16세 미소속 신규 후보 자유계약은 연봉 0원입니다. 드래프트 연결로 선정된 14~16세는 연봉 1,000만원 유형을 유지합니다. 관리비는 18차 주간 정산을 사용합니다. 연습생 계약 급여의 별도 지급일은 여전히 미정이므로 새 지급 시점을 만들지 않습니다.

17세 이상 소속 연습생은 비시즌 4주차, 또는 정규 시즌 중 중도 방출로 생긴 결원의 월요일에만 데뷔할 수 있습니다. 실제 프로/2군 자리가 필요합니다. 첫 프로 연봉 3,000만원 고정, 기간 1~2시즌입니다. 고정 연봉이므로 거절 뒤 금액을 올리지 않고 동일 기준 수락 확률 80%로 기간 제안을 최대 3회 합니다. 실패하면 연습생을 유지합니다.

프로가 다시 연습생으로 돌아가는 것을 차단합니다. 데뷔 시즌·은퇴일을 기록합니다. 무소속 2년 은퇴는 실제 연간 드래프트 결과 2개가 연결되었을 때만 판단합니다. 아직 연간 드래프트가 없는데 가상의 미지명 결과를 만들어 은퇴시키지 않습니다. 은퇴 후 시장·드래프트 계약 API에서 다시 영입하지 못하며 기존 기록은 남습니다.

## 16~17. 재정과 AI 참여

모든 현금 이동은 18차 장부로 처리합니다. 시장 계약에 계약금/영입료를 만들지 않습니다. 급여 회차는 4·8·12·16·20·24주를 유지하고, 이전/이후 계약의 유효일수로 나눕니다. 같은 날 여러 번 이적한 0일 계약 구간은 청구하지 않습니다. 승계로 쪼개진 원 계약의 합계 반올림은 마지막 유효 구간에서 보정합니다.

강제 매각은 실제 계약 승계·소유권·현금 지급·판매 팀 채무 우선 상환을 한 트랜잭션에서 수행합니다. 연봉 높은 프로부터 가격 연봉의 1/2, 구매자 예산/자리를 검증합니다. 위약금은 없습니다. 구매자가 없으면 거래/현금 생성 없이 채무가 남습니다. 플레이어가 모르는 사이 강제로 매입 대금을 내지 않도록 자동 구매자는 AI 기획사로 제한합니다. 플레이어는 자기 기획사의 강제 매각을 명시적으로 실행할 수 있습니다.

9개 AI는 같은 API로 유한 만료 계약 재계약, 실제 필요시 FA 경쟁, 자유계약 연습생, 데뷔, 거래 제안·역제안·거절·수락, 공개된 더 나은 저비용 대안에 따른 방출, 채무 매각을 판단합니다. 자금/정원/채무/기간 실패 시 강행하지 않습니다. 위험 판단과 점수 정책만 있고 AI 전용 자금·계약 성공 보너스는 없습니다.

## 18. 비시즌 4주 연결과 20차 범위

- 1주: 재계약/만료 정리 준비·방출·월요일 거래. 기존 미정 계약은 자동 만료하지 않음.
- 2주: 새로 구현할 연간 통합 드래프트가 확정 지명을 계약 서비스에 전달할 연결 API 준비.
- 3주: FA 공개 입찰·미지명 연습생 자유계약·허용된 거래.
- 4주: 데뷔 계약·선수단 정리. 없는 선수를 만들거나 무료 프로 계약을 강행하지 않음.

**신규 70명 생성·특별 유망주 선정·연간 3라운드 드래프트 진행 UI는 기존 서비스가 없어 구현하지 않았습니다.** 요청서가 허용한 20차 범위로 남깁니다. `connect_draft_pick()`은 확정 지명권/종류를 저장하고 미성년 자동 계약 또는 성인 협상을 연결합니다. 지명권 없는 일반 시장 버튼으로 2주차 드래프트 계약을 우회하지 못합니다. 성인 3회 실패는 지명권을 소모하고 FA로 남깁니다. 신규 후보는 실제 지명권 연결 전까지 고정 추정 범위만 공개합니다.

최초 16라운드 드래프트 진행·기존 160명 이력은 바꾸지 않았습니다. 기존 완료 검증만 선수 이동 후에도 원래 지명 기록을 검증하도록 수정했습니다. 첫 드래프트를 다시 돌리거나 기존 1~3라운드 계약을 소급 협상하지 않습니다.

## 23. 발견한 오류와 수정

- 선수 이동 뒤 초기 드래프트 화면이 현재 소속 16명을 다시 요구하던 오류: 원래 지명 이력으로 검증.

- 비공개 후보 건강을 AI 평가에 직접 곱하던 오류: 비공개 건강은 중립 가정으로 처리하고 조회하지 않음.
- AI 역제안 현금이 float여서 거절되던 오류: 정수 원 단위·만원 반올림 적용.
- FA 공개 입찰 전 열어 둔 직접 협상으로 시장을 우회하던 경로: 제안 확정 직전에 공개 입찰 재검증.
- 동일 월요일 반복 이적의 0일 구간이 급여 반올림에 끼어들던 경로: 0일 구간을 청구·배분에서 제외.
- 거래 후 이전 팀 급여 이력이 프로필에서 빠지던 연결: 모든 이전 기획사의 저장 명세 조회.
- AI 역제안의 실제 금액/선수를 확인하기 어려운 화면: 선택 시 입력란과 확인 창에 저장된 실제 조건 표시.

- 비시즌 계약 만료로 선수단이 비었을 때 리더 검사 때문에 FA 주차 진입까지 막히던 교착: 최초 편성 검사는 유지하고 비시즌 리더 조건만 분리. 다음 정규 시즌 전 선수단·리더 준비 안내 추가.
