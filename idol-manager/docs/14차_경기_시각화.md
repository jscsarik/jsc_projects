# 14차 정규 경기 시각화 UI

## 실행과 화면 구성

기존 `실행하기.bat`로 실행하고 **정규 경기 → 오늘 경기 선택 → 출전자 선택 → 경기 시작** 순서로 진행합니다. 새 게임 생성이나 DB 마이그레이션은 필요하지 않습니다. DB 버전은 **9** 그대로입니다.

기존 엔진이 결과와 출전자·판정 이벤트·피로/부상 처리를 먼저 저장한 뒤 **경기 진행** 탭에서 같은 이벤트를 재생합니다. 경기 시작 버튼만으로 가짜 화면이나 별도 결과를 생성하지 않습니다.

- 상단: 두 기획사 이름과 현재 성공 횟수, 진행률, 기본 판정 틱·개별 판정 수.
- 중앙: 양쪽 기획사의 실제 출전자 카드와 큰 VS, 날짜·콘텐츠 정보.
- 카드: 비율을 유지한 사진, 이름, 성공 횟수, 현재 상태, 저장 당시 1군 리더 배지.
- 하단: 저장 이벤트와 일치하는 최근 5개 로그, 일시정지/재개·상세 진행표·스킵.
- 기존 경기 결과·개인 기록·능력치별 기록·리그 순위 탭은 유지합니다.

1명은 큰 사진, 2~3명은 중간 크기, 4~5명은 작은 카드로 표시합니다. 너비에 따라 팀별 카드가 1~3열로 배치되며 작은 화면에서는 팀 영역을 스크롤할 수 있습니다. 한쪽 출전자가 없는 경우 출전 가능 선수 없음/몰수 안내를 표시하고 실제 판정 이벤트를 만들지 않습니다.

사진은 기존 원본을 수정하지 않고 별도 크기의 썸네일 캐시로 비동기 로드합니다. 한글 경로를 지원하고 누락·손상 파일은 기존 '사진 없음' 플레이스홀더를 사용합니다. 원래 명단 썸네일 크기와 캐시 키는 그대로 유지합니다. 확대 사진 캐시는 `data/battle_thumbnails/`이며 SQLite 게임 데이터와 별개입니다.

## 성공·실패 연출과 시간 표시

`QVariantAnimation`으로 **0.35초** 동안 성공은 초록색, 실패는 분홍색 테두리를 강조한 뒤 기본색으로 돌아옵니다. 성공 시 `+1 성공`, 실패 시 `실패`, 리더 추가 시 별도 상태 문구와 로그를 표시합니다. 같은 틱에 여러 출전자가 판정받으면 해당 카드들을 함께 강조합니다. 연출은 저장된 판정의 시각화이며 확률·주사위·승패 계산을 호출하지 않습니다.

정규 경기는 한 선수당 기본 60회이며 여러 선수의 동시 판정은 **60개 기본 틱**으로 묶여 있습니다. 따라서 화면은 `기본 판정 틱 X / 60`과 `개별 판정 X / 전체 이벤트 수`를 구분합니다. 전체 개별 판정 수는 실제 저장 이벤트 수이며 리더 추가·데스매치를 포함합니다. 데스매치에서는 별도 회차와 10틱 진행으로 표시합니다. 기본 0.5초/틱(약 30초)과 데스매치 약 5초/묶음은 변경하지 않았습니다.

## 스킵·일시정지·BGM

**일시정지**는 이벤트 타이머와 실행 중인 카드 애니메이션을 모두 멈춥니다. **자동 진행 · 재개**를 누르면 현재 위치에서 이어집니다. 다른 탭/화면으로 이동하면 일시정지하며 복귀 후 재개 버튼을 누릅니다. **스킵**은 남은 저장 이벤트의 성공 수만 반영하고 기존 결과 탭으로 이동합니다. 반복 클릭해도 재계산·중복 저장하지 않습니다. 종료 시 타이머·애니메이션·사진 로딩 작업을 정리합니다.

기존 BGM 연결을 유지했습니다. 실제 경기 관전 탭은 battle, 다른 탭/결과/일반 화면은 default입니다. 관전 탭에서 일시정지한 동안에는 battle을 유지합니다. BGM 관리 코드·설정·음악 파일은 변경하지 않았습니다.

## 원본 데이터 보호

실제 세이브를 다음 경로에 SQLite 백업한 뒤 임시 DB와 복사본에서 테스트했습니다.

`data/backups/idol_manager_before_battle_visual_development_20261027_220755_477626_KST.sqlite3`

이번 작업 시작 시 원본은 버전 9·absolute_day 0(revision 1), 드래프트 160건·정규 완료 경기 0건 상태였습니다. 이전 작업 보고 시점의 게임 상태를 강제로 복원하지 않고 현재 상태를 기준으로 보존했습니다.

원본 전체 테이블 행, 정규 일정 585건, 특별전 6건, 드래프트, 선수단·리더·능력치·잠재력·피로/부상·자금·날짜가 작업 전과 동일한지 비교했습니다. assets 파일 462개와 BGM 설정도 해시로 확인했습니다. SQLite 무결성·외래키 오류는 없습니다. 비UI 게임 소스와 설정 파일 41개도 작업 전 해시와 같으며 엔진·서비스·마이그레이션·BGM·날짜 코드는 수정하지 않았습니다.

보존 결과는 `.test-artifacts/visual_preservation.json`에 저장합니다. 실제 원본에서 새 경기를 실행하거나 날짜를 진행하는 시험은 하지 않았습니다.

## 제한

공통 배틀 위젯은 현재 2팀용입니다. 특별전 5팀 화면에는 아직 연결하지 않았으며 기존 특별전 UI를 유지합니다. 특별전 규칙이나 경기 엔진·부상·피로 계산은 변경하지 않았습니다. 작은 창에서는 카드와 상세 표 스크롤이 필요할 수 있습니다. 31주 시즌·포스트시즌·성장·FA·계약·새로운 경기 규칙·무거운 애니메이션은 추가하지 않았습니다.
