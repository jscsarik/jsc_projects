# 관리 화면·대결 무대 및 표 크기 조절

## 사용 방법

- **화면 영역 비율:** 정규 경기·포스트시즌·특별전에서 위쪽 경기 목록과 아래쪽 탭 사이의 **위아래로 드래그하여 영역 크기 조절** 경계선을 잡아 움직입니다. 아래로 내리면 위쪽 목록이 커지고, 위로 올리면 아래쪽 출전자/결과 화면이 커집니다. 표 열 너비와 별개의 설정입니다.
- 경기 목록의 기존 최대 높이 제한을 제거했습니다. 영역이 완전히 사라지지 않도록 최소 높이만 유지합니다. 화면별 비율은 `ui_layout.ini`에 저장되며 창 크기 변경·재실행 후에도 복원됩니다. 관전 중 목록을 접었다가 다른 탭으로 돌아와도 저장 비율을 유지합니다.
- 표 제목의 열 경계를 드래그하면 해당 열 너비를 조절합니다. 마지막 열도 자유롭게 줄이거나 늘릴 수 있습니다.
- 화면 이동·검색·정렬·새로고침 후에도 직접 정한 너비를 유지하고, 재실행하면 표별 설정을 불러옵니다.
- 표 제목을 우클릭하면 **이 표의 기본 열 너비로 복원**, **행 높이 조절…**을 선택할 수 있습니다. 행 높이는 해당 표 전체에 적용합니다. 같은 열에 속한 셀은 열 너비를 공유합니다.
- 설정은 게임 DB 옆 `ui_layout.ini`에 저장합니다. 일반 설치 경로는 `C:\정승찬\IDOL_Manager\data\ui_layout.ini`입니다. 게임 세이브 스키마는 변경하지 않습니다.

## 디자인 방향

관리 화면은 라벤더·블러시 핑크 배경, 둥근 버튼과 표, 선택 메뉴 강조, 얇은 행 구분으로 바꿨습니다. 기존 표 기반 정보 탐색과 정렬·검색·사진은 유지합니다.

정규 경기와 같은 화면을 재사용하는 포스트시즌의 대결 무대는 어두운 플럼·네이비 배경, 큰 팀 점수, 선명한 VS, 성공·실패 테두리 효과를 사용합니다. 데스매치는 분홍색 SUDDEN DEATH 표시로 구분합니다. 관전 탭에서는 경기 목록을 접어 사진 공간을 확보하고, 다른 탭으로 돌아가면 목록을 다시 표시합니다.

특별전에는 공통 관리 테마·표 크기 조절과 관전 중 목록 접기를 적용했습니다. 이번에 특별전용 새 사진 대결 엔진이나 새로운 게임 규칙은 추가하지 않았습니다.

모든 점수·효과는 이미 저장된 판정 이벤트를 표시합니다. 스킵·일시정지·재생으로 경기 결과를 다시 계산하지 않습니다. 음악 전환 로직도 유지합니다.

## 검증

Windows 네이티브 창에서 4개 테스트가 통과했습니다. 열 조절 및 화면 재진입 후 너비 유지, 관리 화면 조회 중 DB 불변, 대결 관전과 스킵 전후 저장 결과 일치를 확인했습니다. 테스트 경기는 임시 DB에서만 진행했습니다.

영역 비율 수정 후 Windows 검증은 **5개 모두 통과(4.754초)**했습니다. 실제 경계선을 드래그해 경기 목록이 커지는지, 새로고침과 게임 재실행 후 비율이 유지되는지, 그동안 DB가 변하지 않는지를 추가 확인했습니다. `ui_regions_resized.png`는 임시 세이브의 조절된 화면입니다. 아래 전체 테스트 수치는 앞선 디자인 작업 당시 결과이며 영역 비율 변경 후의 추가 회귀 결과는 `panel_regions_regression.log`에 별도로 남깁니다.

영역 비율 변경 후 드래그·정규 경기·사진 대결·특별전·포스트시즌 UI 회귀는 **29개 실행, 28개 통과, 1개 초기 편성 조건 불일치로 건너뜀, 실패·오류 0개(106.789초)**입니다. 실제 세이브의 경기 진행이나 날짜 변경은 수행하지 않았습니다.

전체 자동 테스트는 **323개 실행, 321개 통과, 2개 조건 불일치로 건너뜀, 실패·오류 0개(264.320초)**입니다. 건너뛴 두 항목은 실제 세이브가 이미 초기 편성/초기 교착 상태를 지난 경우에만 실행하는 복사본 시나리오입니다. 일반 임시 DB의 해당 로직 시험은 별도로 통과했습니다.

마지막 관전 공간 조정 후 경기·특별전 UI 및 사진 대결 회귀를 다시 실행해 **25개 중 24개 통과, 1개 동일 조건으로 건너뜀, 실패 0개(66.885초)**를 확인했습니다. 로그는 `ui_refresh_replay_final.log`입니다.

전체 자동 테스트 결과는 `.test-artifacts/ui_refresh_full_tests.log`, Windows 결과는 `ui_refresh_windows.json`, 캡처는 `ui_refresh_management.png`, `ui_refresh_battle.png`에 있습니다.

실제 세이브는 읽기 전용 비교로 검사했습니다. 기존 최신 백업과 모든 45개 테이블 행, assets 462개와 BGM 설정이 일치합니다. 드래프트·선수단·일정·능력치·성장·자금·DB 버전은 이번 UI 변경으로 수정하지 않았습니다. 자세한 비교는 `.test-artifacts/ui_refresh_preservation.json`입니다.

실행 중인 창을 닫고 기존 `실행하기.bat`로 다시 실행하면 새 디자인을 사용합니다. 새 게임 생성은 필요하지 않습니다.
