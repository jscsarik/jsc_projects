# 21차 신규 유입 · 통합 드래프트

## 실행과 조작

기존 `실행하기.bat`로 실행합니다. 새 게임 생성은 필요하지 않습니다.
비시즌 1주차에 미등장 사진 70명을 등록하고, **통합 드래프트** 메뉴에서 현황을 확인합니다.
사진이 부족하면 `assets/idols/`에 서로 다른 사진을 넣고 **사진 추가 · 다시 스캔**을 누릅니다. 70명 등록 전에는 2주차 진입이 차단됩니다.
비시즌 2주차에 **3라운드 시작**, 후보 선택 후 **지명 확정**을 사용합니다. 성인은 연봉·계약기간 입력 후 **계약 제안 확정**을 누릅니다.
**AI 다음 내 차례까지**는 플레이어 차례에서 멈춥니다. 사진·검색·정렬·페이지 이동·공통 프로필을 지원합니다.

계약 가능한 후보가 없으면 **지명권을 보존하고 자동 진행을 중단**합니다. 기존 재정 관리에서 문제를 해결한 뒤 같은 순서에서 재개합니다. 대체 선수 지급이나 계약 검증 우회는 없습니다. 성인 협상은 완료한 뒤 다음 지명으로 이동합니다.

## 구현 규칙

| 항목 | 처리 |
|---|---|
| 신규 70명 | 시즌 이벤트·시드 저장, 원자적 생성, 재실행 중복 방지 |
| 나이 | 14~16세 정확히 60명, 기존 생성기 성인 범위 17~26세 10명 |
| 능력치 | 기존 생성기·유형·CA/PA 재사용, 최초 공개되는 미등장자만 생성 |
| 건강 | 기존 최대 90·생일 -1 유지, 기존 생일 재정산·소급 감소 없음 |
| 특별 유망주 | 신규 중 21세 이하 2명 비공개 저장. 기존 별도 보너스가 없어 새 PA/성장 보너스는 만들지 않음 |
| 인물 ID | 기존 ID 보존, 새 사진 UUID 저장, 동명이인 허용, 같은 바이트 사진 중복 제외 |
| 신규 제외 | 등장·지명·소속·FA·계약·은퇴·기존 미지명 이력의 인물 |
| 사진 부족 | 부분 능력치 생성 없이 부족 수 표시, 사진 추가 후 재시도 |
| 후보 풀 | 신규와 기존 FA·미소속, 유효 계약·은퇴·당해 기지명자 제외 |
| 3라운드 | 확정 정규 순위 역순→정순→역순. 10개사 각 3회, 총 30회. 동률 결정전 미완료 시 시작 차단 |
| 공개 | 미지명은 저장된 5개 정수 범위·추정 CA, 지명 후 정확 CA. 실패 후에도 정확 공개 유지 |
| 비공개 | 실제 PA·특별 유망주·성장 유형은 공개 DTO/AI에서 제외 |
| 14~16세 | 연 1,000만 원 드래프트 연습생 자동 계약, 프로 데뷔 아님 |
| 성인·기존 FA | 19차 시장연봉·1~2시즌·최대 3회·5% 재제안·기존 확률 재사용 |
| 정원·예산 | 기존 프로 16명·2군 11명·채무·예산 검증. 자동 방출 없음 |
| 협상 실패 | 지명권 소모, FA 유지, 당해 재지명 금지, 3주차 시장 연결 |
| 미지명자 | 미소속/FA 유지. 청소년 자유계약 연습생·성인 FA 입찰, 기존 시장 마감 유지 |
| 프로필 | 공통 상세에 공개 수치·지명 시즌/라운드/순번/기획사/계약 결과 연결 |
| 과거 경력 | 기존 FA 데뷔 시즌 보존, 새 프로 다음 시즌 데뷔, 연습생 데뷔 없음 |

시즌 1 비시즌은 화면에 **시즌 2 지명**으로 표시합니다. 내부 키는 19차 서비스 호환을 위해 종료 시즌을 사용하고 대상 시즌은 별도 저장합니다.
기존 창단 200명·16라운드는 유지합니다. 비시즌 3주차 이후 또는 구형 지명 기록이 있는 세이브는 되돌리지 않고 다음 적용 시즌부터 시작합니다.
미등장 시기의 비공개 과거 성장 기록은 삭제하지 않고 신규 프로필에서만 노출을 제한합니다.

AI는 공개 범위/현재 능력치, 팀 구성·강점·나이 및 기존 예산 검증을 사용합니다. 안정형·균형형·공격형 이름을 재사용합니다. 기존 기획사별 성향 배정 저장이 없어 `config/annual_draft.json`의 `default_style`과 `agency_styles`로 분리했으며 기본 balanced입니다. 숨겨진 정보나 수락 보너스는 사용하지 않습니다.

## 파일과 DB

DB 버전 **16**, 변경 전 SQLite 백업, 트랜잭션 마이그레이션입니다. 기존 추정치 값·변경 금지 트리거는 보존하고 참조 대상을 전체 아이돌로 확장합니다.
