# 900×1600 세로형 화면 배치

가로 900 × 세로 1600 안에 들어가는 세로형 모드를 추가했습니다. 긴 목록과 상세 정보는 페이지 이동으로 제공하며, 게임 규칙과 SQLite 스키마는 변경하지 않았습니다.

## 사용 방법

- 게임을 완전히 종료한 뒤 `실행하기.bat`으로 재실행합니다.
- 기본 창은 Windows 제목줄·테두리를 포함해 900×1600 범위에 맞춥니다. 현재 모니터의 작업 가능 영역이 작으면 해당 영역에 맞춰 더 작게 엽니다.
- 창 폭 1000 이하에서 왼쪽 메뉴 대신 상단 **화면 이동** 선택기를 사용합니다.
- 표 아래 **◀ / ▶**: 명단의 행 페이지를 이동합니다.
- **정보 1/N**: 같은 선수의 능력치·계약·기록 등 열 묶음을 전환합니다. 사진·이름 또는 식별 열은 함께 유지합니다.
- **선택 상세**: 현재 행에 이미 공개된 전체 열의 값을 별도 창에서 페이지로 확인합니다. 숨겨진 CA/PA를 새로 조회하지 않습니다.
- 정보 탭이 많은 화면은 긴 탭 제목을 가로로 밀지 않고 선택기로 전환합니다.
- 프로필 비교는 선수별 탭으로 전환합니다. 긴 설명·경력은 설명 이전/다음으로 확인합니다.
- 경기 관전 중에는 위쪽 경기 목록을 접고 카드 무대에 공간을 배분합니다. 출전자 선택으로 돌아가면 목록을 복원합니다. 상세 진행표를 켜면 무대와 표를 전환하고, 기존 표시/숨김 연결도 유지합니다. 높이가 작은 화면에서는 카드 3열과 작은 사진을 사용합니다.
- 세로형에서는 패널을 창 안에 고정합니다. 폭 1000을 넘게 넓히면 기존 사이드바·도킹 기능을 사용할 수 있습니다.

모든 사람·모든 기록을 동시에 축소해서 한 화면에 놓는 방식은 아닙니다. 승인받은 페이지 이동·선택 상세 방식을 사용합니다. 셀의 긴 문구는 전체 상세에서 확인할 수 있습니다.

- `tests/test_portrait_layout.py`: 페이지·검색·정렬·체크·선택·설정·화면 전환·비교·대결 회귀 테스트.
- `tools/verify_portrait_ui.py`: 실제 세이브의 읽기 전용 SQLite 백업 복사본을 사용한 화면 검사·캡처.
- `README.md`, 이 문서.

## 검증 방법과 보존

검사 도구는 원본 SQLite를 `mode=ro`로 열어 임시 DB에 백업합니다. 초기화·경기 진행·이적·날짜 변경은 원본에서 수행하지 않습니다. UI를 열기 전후 임시 DB의 전체 SQL 덤프가 일치하는지 검사합니다. 원본 사진·음악을 수정하지 않습니다.

- 표는 기존 모델/프록시와 내부 ID를 그대로 사용합니다. 검색·정렬은 전체 목록에 적용되고, 표시 행만 페이지로 나눕니다.
- 선수 체크 상태는 페이지 전환으로 사라지지 않습니다.
- 기존 열 너비 저장값은 자동 맞춤으로 덮어쓰지 않습니다.
- 세로/가로 스크롤바 숨김뿐 아니라 실제 스크롤 가능 범위가 0인지 검사합니다.
- 화면/탭/프로필/비교와 5대5 무대 **52개 상태**의 컨트롤이 창 밖으로 나가는지 검사합니다.
- 정확한 크기 렌더링: Qt offscreen, 한글 맑은 고딕 로드, 메인 내용 900×1560 및 프로필 860×1480. 결과 `.test-artifacts/portrait/audit.json`.
- Windows 네이티브: 실제 Windows Qt 백엔드에서 같은 상태 검사. 현재 모니터의 가용 높이 제한으로 일부 창이 약 1061픽셀 높이로 조정되어 더 작은 높이에서도 검사했습니다. 결과 `.test-artifacts/portrait_windows/audit.json`.
- 물리적인 900×1600 세로 모니터에서 직접 전체 화면을 눈으로 확인하는 검증은 이 장비에서 실행하지 못했습니다. 렌더링 크기 검사와 네이티브 실행 검사를 구분합니다.

전체 자동 테스트 최종 수치는 아래에 기록합니다.


## 화면 전환 회귀 수정

- 기존 코드에서 특정 행을 선택하면 그 행이 있는 페이지를 즉시 표시합니다. 내부 선수/경기 ID와 선택 인덱스는 바꾸지 않습니다.
- 관전 종료·결과 탭 전환 시 경기 목록을 즉시 복원합니다. 지연 갱신으로 다음 더블헤더 또는 과거 결과를 잘못 클릭하던 경로를 막았습니다.
- 표를 페이지 컨테이너로 감싼 뒤에도 기존 상세 진행표 버튼의 표시/숨김 이벤트를 도킹 패널까지 전달합니다.
- 게임 창 종료 시 전역 UI 이벤트 필터와 페이지 갱신 타이머를 정리합니다.

이 수정은 표시/선택 타이밍에 한정합니다. 당일 경기 진행·승패·판정 이벤트·중복 저장 방지·날짜 진행 규칙은 기존 서비스를 그대로 사용합니다.

- 새 페이지/전체 행·열 접근/선수 체크/검색·정렬/열 설정 보존/기본 창 크기/비교/5대5/즉시 선택과 관련 경기 GUI 검사를 포함합니다. 기본 창 크기는 Windows 네이티브에서도 별도 확인했습니다.
- 정확한 크기 렌더링 **52개 상태**, Windows 네이티브 **52개 상태** 모두 스크롤 범위/보이는 컨트롤의 창 밖 넘침 0. 두 검사에서 조회 전후 복사본 DB 전체 덤프 동일.
- 실제 세이브를 초기화하거나 날짜·능력치·잠재력·일정·드래프트·계약·자금을 변경하지 않았습니다. 기존 사진과 음악도 수정하지 않았습니다. 새 DB 마이그레이션은 없습니다.

실행 중인 게임을 완전히 종료한 뒤 재실행해야 새 화면 배치가 적용됩니다.
