# 프로필 시즌 기록 · 성장/계약 요약 · 필요 휴식 통합

## 변경 내용

- 경기 기록의 기본 화면을 **시즌별 · 통산**으로 구성했습니다. 시즌/당시 소속/실제 경기/주요 능력치 성공/일반 능력치 성공을 먼저 표시합니다. 이적한 시즌은 소속별 기록과 시즌 합계가 나오며 마지막에 통산을 표시합니다. 좁은 화면에서는 나머지 항목을 정보 페이지로 확인합니다.
- **주요 능력치 성공 = main 그룹**, **일반 능력치 성공 = support(무작위) 그룹**입니다. 무작위 그룹에서 주요 능력치가 나와도 일반 능력치 성공에만 포함합니다. 두 그룹을 합친 지표는 **기본**이라고 표시합니다.
- 정규/PS 경기 진행 카드·실시간 표·결과 표와 특별전 표에도 같은 명칭을 적용했습니다. 리더 추가·데스매치는 별도입니다. 판정 수·확률·점수·성장 집계 방식은 바꾸지 않았습니다.
- 시즌·통산 성공률은 성공 수와 시도 수의 합계로 계산합니다. 이벤트나 능력치별 집계가 없는 과거 기록은 주요/일반 성공을 임의로 나누지 않고 기록 없음으로 표시합니다.
- 기본 조회는 정규 경기이며 특별전·PS·결정전은 기존 구간 선택으로 조회합니다.
- 성장 이력은 **2줄 요약 + 날짜/종류/신분/실제 변화/사유** 표로 줄였습니다. +0으로 채워진 능력치 열은 없앴습니다. 변화 없는 정산은 기본 숨김이며 **변화 없는 기록도 보기**로 확인할 수 있습니다. 기록을 삭제하는 기능이 아닙니다. 정산 설명은 접혀 있습니다.
- 계약·경력은 **현재 소속/연봉/계약 기간/지명/통산 수상**만 요약합니다. 없는 항목을 여러 줄로 늘어놓지 않습니다. 지급·이적·수상 근거 등 기존 상세 내용은 **자세히 보기**에 보존했습니다.
- 피로·부상과 선수단 표의 **필요 휴식**은 앞으로 더 쉬어야 하는 주 수입니다. 이전 ‘남은 휴식’ 값을 사용하며 별도 총 필요 휴식·완료 휴식·남은 휴식 칸을 중복 표시하지 않습니다. 예: 총 2주 필요, 1주 휴식 완료 → 필요 휴식 **1주**.
- 2주 이하 등록 시 0주, 일반 월요일 교체는 인물별 당일 1회, 부상·특별전 예외 등 앞서 수정한 규칙은 유지합니다.
- 세로형 화면에서 정보 탭이나 긴 상세 설명이 보이지 않던 래퍼 표시 문제도 함께 수정했습니다. 접은 상세 설명은 빈 페이지 영역을 차지하지 않습니다.

## 검증

서로 다른 관련 테스트 **12개 최종 PASS**입니다.

- 신규 시즌 표/그룹 성공 수/가중 통산/같은 시즌 이적 합계/누락 기록/후보 비공개/관전과 스킵 동일 결과: 5개
- 기존 배틀 카드, 기록실 Windows UI, 능력치별 집계: 3개
- 성장/계약 접기와 +0 숨김, 필요 휴식 통합 UI, 피로·부상 요약, 월요일 재변경 차단: 4개

테스트용 두 시즌 고정 기록과 임시 DB만 사용했으며 시즌을 자동 시뮬레이션하지 않았습니다. 관전/스킵 검사도 저장된 동일 이벤트를 사용하고 엔진 호출을 금지했습니다. 신규 검사에서 잘못 사용한 테스트 도우미 호출을 수정해 해당 항목만 재검사했습니다.

주요 로그: `.test-artifacts/season_match_labels.log`(최초 4 PASS/도우미 오류 1), `season_match_skip_fix.log`, `season_match_ui_final.log`, `season_profile_visible.log`, `profile_summary_rest.log`, `profile_rest_limit_regression.log`.

Windows 캡처: `.test-artifacts/profile_seasons_windows.png`, `profile_contract_compact_windows.png`. 실제 세이브 대신 고정 선수/누락 사진 플레이스홀더를 사용했습니다.

원본 DB는 읽기 전용으로 접근했습니다. 작업 중 사용자가 게임 날짜를 진행한 상태를 되돌리지 않았습니다. 현재 진행 상태로 만든 백업/복사본 조회 보존 검사는 `season_match_preservation.log`에서 PASS이며 당시 원본 84개 테이블과 assets 462개가 동일했습니다. 현재 플레이 데이터를 대신 생성하거나 정산하지 않았습니다.

전체 테스트 반복·장기 시즌 시뮬레이션은 생략했습니다. 이전에 저장되지 않은 과거 기록은 생성하지 않았습니다. 실행 중인 게임은 재실행하면 새 UI가 적용됩니다.
