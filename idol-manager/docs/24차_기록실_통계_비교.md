# 24차 기록실 · 통계 · 비교

## 실행과 화면

기존 `실행하기.bat`로 실행한 뒤 **기록실**을 선택합니다. 새 게임 생성이나 과거 경기 재실행이 필요하지 않습니다.

5개 탭을 추가했습니다.

1. **역대 리그**: 시즌별 최종 정규 순위, 역대 챔피언, 최고 기록. 챔피언을 더블클릭하면 저장된 시리즈 대진을 확인합니다. 최고 기록 동률자는 모두 표시합니다.
2. **선수 기록**: 현재 소속과 무관하게 공개 선수·FA·은퇴 선수까지 조회합니다. 이름 클릭은 17차 공통 프로필, 하단 버튼은 시즌별 소속·합계·성장·수상·이적 이력입니다.
3. **기획사 기록**: 통산/시즌 정규 성적, 우승, 개인상 배출, 현재 현금·채무. 기획사를 더블클릭하면 시즌별 추이 표·과거 계약/소속 근거·재정·특별전·PS 결과를 확인합니다.
4. **콘텐츠별 성적**: 정규 30종과 완료된 특별전/PS/결정전을 구분합니다. 콘텐츠 선택, 기획사 필터, 선수 이름 검색을 지원합니다.
5. **기록 비교**: 선수 2명 또는 기획사 2곳을 선택합니다. 현재 능력치·연봉·건강과 과거 경기 기록을 구분하며 나이·연봉·채무 등에 우열 점수를 붙이지 않습니다.

상단에 통산/시즌, 경기 구간, 기획사, 이름 검색을 배치했습니다. 선수 표에는 현재 신분과 조회용 최소 시도 수 필터도 있습니다. 기획사 필터는 경기 당시 소속을 기준으로 하므로, 현재 다른 기획사에 있거나 은퇴한 선수의 과거 기여를 찾을 수 있습니다.

리그·기획사의 **정규 성적과 공식 수상/최고 기록은 정규 기준**입니다. 경기 구간 필터는 선수·콘텐츠·선수 비교에 적용됩니다. 전체 경기 조회에서도 정규·특별전·PS·결정전 출전을 별도 열/경력 행으로 표시합니다.

숫자 열은 숫자로 정렬합니다. 성공률 열의 단위는 %이고, 시도 수 0이면 `기록 없음`입니다. 많은 열·행은 기존 표 페이지 이동/정보 페이지와 선택 상세를 사용합니다. 기존 도킹·열 크기 설정을 유지하며 맑은 고딕과 연한 파랑·화이트 표 스타일을 적용했습니다. 사진·로고는 기존 캐시와 누락 이미지 플레이스홀더를 사용하고 보이는 행부터 요청합니다.

상단 **시즌 시상식**은 기존 20차 화면으로 연결합니다. **포스트시즌 결과**는 선택 시즌의 저장된 대진·완료 경기만 읽는 상세 창입니다. 통산 조회에서 리그/챔피언 행을 선택하면 그 시즌을 사용하며, 선택하지 않으면 최근 시즌을 사용합니다.

## 집계 기준

| 항목 | 단일 기준 |
|---|---|
| 정규 팀 경기·승패 | 완료 일정과 `match_results`/`match_team_stats` |
| 정규 출전 | `match_player_stats`의 경기·선수 기본키, 판정 수나 등록일 수로 세지 않음 |
| 특별전 | 완료 `special_rounds`와 선수·팀 기록. 개최 수는 실제 단계별 대결 수이며 정규 개최에 합산하지 않음 |
| PS·결정전 | 완료 `final_contests`의 저장된 선수/팀 JSON. SQLite JSON 함수로 구간별 집계 |
| 일반 판정 | 저장 이벤트의 main/support를 실제 능력치별로 SQL 집계. 한 이벤트는 한 번만 합산 |
| 구형 기록 | 해당 경기·선수 이벤트가 없으면 기존 능력치 집계만 배타적으로 사용. 그것도 없으면 선수 요약 합계만 사용하고 능력치별 비율은 기록 없음 |
| 성공률 | 성공 합계 ÷ 시도 합계. 시즌별 비율의 단순 평균을 사용하지 않음 |
| 리더·DM | 별도 횟수·성공 수. 일반 성공률에서 제외 |
| 승리/패배 아이돌 | 기존 확정 선정 장부가 있으면 우선, 없으면 선수 요약의 확정 플래그. 두 출처를 더하지 않음 |
| 최종 정규 순위 | `season_finals.final_order_json`과 동결된 순위 자료. 미확정 순위를 확정 순위처럼 표시하지 않음 |
| 정규 승점·특별전·페널티 | 기존 공식 자료를 분리 표시. 동결 자료가 없으면 기존 리그 집계와 특별전/재정 장부 사용 |
| 챔피언 | 저장된 finals/시상식/명예 기록을 중복 없이 시즌당 하나로 조회. 정규 1위와 분리 |
| 개인상 | `individual_awards`의 공식 결과, 수상 당시 기획사 유지. 시상식 재선정 안 함 |
| 이적·은퇴 | 동일 인물 ID의 과거 경기 당시 소속을 유지. 같은 시즌 여러 소속도 별도 행과 시즌 합계로 조회 |
| 과거 선수단 | 계약 유효기간·일별 소속 기록. 현재 선수단을 과거 명단에 소급하지 않음 |
| 기획사 평균 | 현재 소속 1군·2군·임시 프로, 연습생 제외. 건강을 CA에 포함하지 않음 |

기존 통산 뷰 중 일반 판정에 리더 성공까지 포함한 비율이 있어 그 비율을 그대로 사용하지 않았습니다. 원본 기록을 변경하지 않고 일반 판정만 분리한 조회식을 사용합니다.
프로필 콘텐츠 표와 기록실은 `RecordsService.content_players()`를 공유합니다. 판정 수와 출전 수를 먼저 독립적으로 집계하여 다대다 조인으로 출전 수가 부풀지 않게 했습니다.

## 기록이 없는 항목

현재 작업 폴더에는 21차까지의 코드와 기존 다년 날짜/경기 저장 구조가 있으며, 22·23차 전용 시즌 요약·경계 스냅샷 구현은 확인되지 않았습니다. 이번 작업은 저장된 여러 시즌을 조회하도록 구현했습니다.

- 시즌 시작/종료 CA 경계 스냅샷은 없으므로 `기록 없음`입니다. 실제 주간 정산의 능력치 증감과 사유는 표시하되 현재 CA로 역산하지 않습니다.
- 시즌 종료 현금·채무 스냅샷과 정확한 시즌별 총연봉 스냅샷은 없습니다. 장부의 현금 수입/지출·마지막 기록 현금과 계약 당시 연봉을 표시하고, 이를 시즌 종료 값이나 시즌 총연봉으로 부르지 않습니다. 장부 자체가 없으면 0이 아닌 기록 없음입니다.
- 시즌 시작 현금은 해당 시즌 첫날 장부 근거가 있는 경우만 표시합니다.
- 과거 시리즈 점수가 없으면 0:0으로 채우지 않습니다. 확정 우승 기록과 없는 경기 상세는 구분합니다.
- 그래프 대신 동일 데이터를 담은 시즌 추이 표를 제공합니다. 별도 명예의 전당 점수·선수 가치·새로운 상은 만들지 않았습니다.

기록실은 이 누락 데이터를 복구하기 위해 경기를 재실행하거나 시즌을 진행하지 않습니다.

## 검증

**신규 핵심 15개 + Windows GUI 1개 + 기존 프로필 관련 2개 = 서로 다른 자동 테스트 18개 최종 PASS.** 추가로 실제 세이브 복사본 조회·원본 보존 검사 PASS입니다.

- 정규 1~10위, 정규 1위와 챔피언 분리, 2시즌 누적 우승, 실제 출전 수, 승리/패배 아이돌, 능력치별 시도·성공, 리더/DM 제외, 90%와 70%의 가중 통산 72%를 검증했습니다.
- 정규·특별전·PS·결정전 구분, 같은 날 더블헤더 2경기/1날짜, 같은 시즌 이적 전후 1+8경기, 은퇴 후 프로필, 다중 개인상, 두 종류 비교, 미지명 추정 범위·PA 보호, 조회 후 DB/난수 불변과 FK/integrity를 검사했습니다.
- 이벤트와 집계가 함께 있어도 중복하지 않는 것, 이벤트가 없을 때 기존 능력치 집계로 복구되는 것을 확인했습니다.
- Windows Qt `windows` 플랫폼에서 실제 창을 렌더링해 숫자 정렬, 선수 경력 버튼, 공통 프로필, 비교, 기획사/PS 상세, 시상식 이동과 복귀를 확인했습니다. 초기 GUI 검사에서 누락된 import를 수정했습니다. 수상 근거가 비어 있던 테스트 픽스처도 실제 저장 형식으로 수정했습니다. 최종 GUI 검사는 PASS입니다.
- 고정 예제는 2시즌의 정규 10경기와 특별전·PS·결정전 각각 1개입니다. 실제 경기 엔진을 돌린 시즌 시뮬레이션이 아닙니다.
