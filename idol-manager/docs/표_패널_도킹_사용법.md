# 표 패널 도킹·크기 조절 사용법

모든 표에 도킹 패널을 적용했습니다. 기존 열 너비 조절과 별도로 표가 들어 있는 영역 전체를 조절할 수 있습니다.

- **패널 사이의 보라색 경계선 드래그**: 위아래 또는 좌우 비율 조절.
- **패널 제목줄 드래그**: 같은 작업영역에서 위치 이동. 가장자리에는 나란히 배치하고, 다른 패널 위에는 탭으로 묶을 수 있습니다.
- **제목줄 더블클릭 또는 제목줄의 분리 버튼**: 별도 창으로 분리. 분리한 창은 가장자리에서 원하는 크기로 조절합니다.
- **제목줄 우클릭 → 원래 작업영역으로 도킹**: 분리 창을 원래 화면으로 돌립니다.
- **제목줄 X**: 패널만 숨깁니다. 선수나 기록을 삭제하지 않습니다.
- **상단 ‘패널 배치 ▾’**: 현재 화면의 숨긴 패널을 다시 표시하거나 기본 배치로 복원합니다. 프로필 창에도 같은 버튼이 있습니다.

크기·위치·도킹·탭·닫힘 상태는 `data/ui_layout.ini`에 자동 저장됩니다. 기본 배치 복원은 UI 설정만 변경하며 게임 세이브에는 영향을 주지 않습니다.

드래프트의 후보/사진·분석/지명 이력/순서, 경기 화면의 목록/상세/진행 무대/판정 기록, 특별전 순위/기록, 명단·선수단·일정·성장·탐색 표, 프로필의 부상·이동·출전 달력·유효 능력치·경기·성장 기록에 적용했습니다. 프로필의 피로·부상 표와 경기 기록 표는 기본적으로 탭으로 묶여 있습니다.

도킹 영역은 게임 화면별로 분리됩니다. 다른 게임 화면으로 이동하면 해당 화면의 분리 창도 숨겨집니다. 같은 화면의 탭을 바꾸면 분리 창은 유지되어 여러 표를 함께 볼 수 있습니다. 프로필 창을 닫으면 그 프로필에서 분리한 표도 닫힙니다. 아직 이용할 수 없는 경기 결과나 게임 자체에서 숨긴 판정 기록은 ‘모두 표시’로 강제로 공개하지 않습니다.

실행 중인 프로그램은 완전히 종료한 뒤 프로젝트의 `실행하기.bat`으로 다시 실행해야 적용됩니다.

## 구현 파일

- `idol_manager/ui/dock_workspace.py`: 공통 도킹 패널, 레이아웃 저장·복원, 숨김·화면 수명 관리.
- `idol_manager/ui/dock_install.py`: 기존 표·모델·버튼 연결을 유지한 채 도킹 영역에 배치.
- `idol_manager/ui/main_window.py`, `profile_dialog.py`: 패널 배치 메뉴 및 종료 처리.
- `idol_manager/ui/match_page.py`, `special_page.py`, `draft_page.py`: 탭 이동 시 사용자 패널 배치를 유지하고 창 크기 변경 시 구형 고정 높이를 재적용하지 않음.
- `tests/test_dock_workspace.py`, `tests/test_dock_ui.py`: 도킹·재실행·데이터 보존 회귀 테스트.
- `tools/verify_dock_ui.py`, `tools/verify_ui_refresh.py`: Windows 실제 Qt 창의 더블클릭·경계 드래그·복원 검사.

게임 DB 스키마, 경기 판정, 성장 확률, 날짜 복구, 드래프트와 선수단 규칙은 변경하지 않았습니다. 테스트 결과는 작업 완료 보고와 `.test-artifacts/dock_full_tests.log`, `dock_windows.log`, `dock_native_refresh.log`를 참조하세요.
