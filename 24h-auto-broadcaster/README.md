# 📡 24h Auto Broadcaster - 24시간 무인 방송 송출 관제 시스템 사용 매뉴얼

[![Developer: 정승찬](https://img.shields.io/badge/개발자-정승찬%20(jscsarik)-blue.svg)](https://github.com/jscsarik)
[![Capstone Design: DIMA](https://img.shields.io/badge/캡스톤디자인-동아방송예술대학교%20방송기술과-darkred.svg)](#)

> **"고가의 방송국 하드웨어 스위처 없이, OBS Studio와 연동하여 24시간 무중단으로 영상을 자동 편성·송출하는 APC 관제 시스템"**  
> 영상 파일을 폴더에 넣기만 하면 실시간 러닝타임 계산과 A/B Roll 핑퐁 스위칭으로 검은 화면(블랙아웃) 없이 24시간 매끄럽게 방송을 송출합니다.

---

## ⚡ 1. 3초 퀵 스타트 (실행 방법)

1. **OBS Studio**를 실행합니다.
   * 상단 메뉴 **[도구] ➔ [WebSocket 서버 설정]**에서 **'WebSocket 서버 활성화'**가 체크되어 있는지 확인합니다.
2. 이 폴더 안에 있는 **[`실행하기.bat`](./실행하기.bat)** 파일을 마우스로 **더블클릭**합니다.
3. 자동으로 필요한 라이브러리(`obsws-python`, `opencv-python`)를 점검한 뒤, 24시간 무인 송출 엔진이 가동됩니다!
4. *(참고)* OBS가 켜져 있지 않더라도 시스템은 가상 시뮬레이션 모드로 자동 작동하여 편성 로직을 정상 테스트할 수 있습니다.

---

## 🎛️ 2. 핵심 방송 송출 기능

### 🔄 핫스왑 (실시간 영상 추가/삭제)
* 방송이 24시간 돌아가고 있는 도중에도, 영상 폴더에 새 비디오 파일을 넣거나 빼도 시스템이 멈추지 않습니다.
* 다음 순서 큐시트 생성 시 새로운 영상 파일들을 자동으로 감지하여 즉각 방송 일정에 편입합니다.

### 🔀 A/B Roll 핑퐁 교차 스위칭 (블랙아웃 0%)
* 하나의 플레이어만 사용할 때 발생하는 다음 영상 로딩 지연(화면 깜빡임)을 없애기 위해, `Player_1`과 `Player_2`를 지그재그로 번갈아 재생합니다.
* 0.15초 사전 버퍼링으로 지상파 방송국 수준의 매끄러운 화면 전환을 실현합니다.

### ⏱️ OpenCV 기반 밀리초 정밀 타이머
* 비디오 파일의 총 프레임과 FPS를 분석하여 실제 상영 길이를 1ms 단위로 정확히 계산하고 큐시트를 자동 동기화합니다.

## ❓ 3. 자주 묻는 질문 (FAQ)

### Q1. 송출을 중단하고 싶을 때는 어떻게 하나요?
> 👉 실행 중인 검은색 콘솔 창에서 키보드의 **`Ctrl + C`**를 누르거나 창 우측 상단의 `X` 버튼을 닫으시면 안전하게 송출이 종료됩니다.
